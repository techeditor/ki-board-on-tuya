# Ki-board 交互说明（v0.3）

> 本文只写用户在键盘上看到和做的事。行为以 [`shared/protocol/protocol.md`](../shared/protocol/protocol.md)
> 为准（尤其是「LCD 菜单与按键灯光」一节），两者不一致时以协议为准。键盘经电脑上的 Companion 对接 Kiro Crew（目前只支持 Kiro Crew）。
> 整体结构见 [`docs/architecture.md`](architecture.md)。

## 1. 键位

六个键 K1–K6，一个旋钮（EC11，可旋转、可按下）。每个键下面一颗灯（LED1–LED6），旋钮旁一颗（LED7）。

普通键和旋钮按下都识别三种手势：

| 手势 | 怎么按 |
|---|---|
| 单击 | 按下后 0.8 s 内松开，且松开后 0.25 s 内没有再按 |
| 双击 | 松开后 0.25 s 内再按一下并松开 |
| 长按 | 按住 0.8 s，到时立即生效，不等松开 |

一次操作只算一种手势。语音键不分手势：按下开始说话，松开结束。

## 2. 默认按键功能（待命时）

| 输入 | 单击 | 双击 | 长按 |
|---|---|---|---|
| K1 / K2 / K3 | 选中对话槽 A / B / C | 切换到第 1 / 2 / 3 个 Kiro Crew 实例（本机 / 远程 Crew） | 无（保留）。绑定会话在设置页“绑定会话”里做 |
| K4 | 有被 ESC 关掉的请求时：重新弹出；否则无 | — | — |
| K5 | 语音键：按住说话，松开结束 | | |
| K6 | 确认（只在输入确认页有效） | 在 Auto 和上次手选的模型之间切换 | 打开模型 / 模式菜单 |
| 旋钮 | 单击：Companion 在电脑上模拟按一次回车 | — | 打开设置页 |
| 旋钮旋转 | 滚动（顺时针向下） | | |

除旋钮长按（固定打开设置页）外，键位可以在 Companion 的键位页里改。三个槽的显示名（默认 A / B / C）
也可以在 Companion 里设置。槽位绑定哪个会话，在键盘设置页“绑定会话”里选，也可以在 Companion 里选。

## 3. 对话槽状态

屏幕左侧三块图标对应 K1–K3 绑定的三个对话，背景色表示对话状态：

| 图标颜色 | 状态 |
|---|---|
| 紫 | 未绑定 |
| 绿 | 空闲 |
| 红 | 忙碌 |
| 橙 | 等待你操作 |
| 蓝 | 有新信息，无需操作 |

对话等待操作时，对应的 K1–K3 键灯**黄色呼吸**。

## 4. 工作状态 ①–⑦

键盘任何时刻处于下面一个状态。

| 状态 | 什么时候进入 | 怎么离开 | 主要按键 |
|---|---|---|---|
| ① 待命 | 开机；其他状态结束后 | 按住语音键 → ②；有请求 → ④；K6 长按 → ⑤；旋钮长按 → ⑥ | 见第 2 节 |
| ② 语音输入 | 按住语音键 | 识别出文字 → ③；没识别出、失败或超时 → ① | 松开语音键结束说话；电脑识别等待结果时 K1 取消 |
| ③ 输入确认 | 识别出文字 | K6 确认 / K1 取消 / 20 s 无操作 → ① | K6 发送；K4 单击删一个字、长按全删；按住语音键重说；K1 取消 |
| ④ 菜单 | 权限审批、提问、回复选项到达（且在 ①） | 选中、ESC、请求已在别处处理、超时 → ① | 见第 5 节 |
| ⑤ 模型 / 模式菜单 | K6 长按 | 同 ④ | 同 ④ |
| ⑥ 设置 / 测试 | 旋钮长按 | 设置页里选 Exit | 只用旋钮：旋转选择、按下进入或确认 |
| ⑦ 系统确认 | 打开配网窗口 / 更换 Wi-Fi、解绑设备（设置页或 K1+K6 组合键）、重置配网、清除蓝牙配对、固件升级 | 确认、取消、10 s 超时 | 松开 K6 确认（按下 K6 不算），K1 取消（默认选中取消） |

**优先级**：⑦ 盖住一切，其次 ⑥，再其次其余状态。

**恢复组合键**：任何界面同时按住 **K1 + K6 约 5 秒**，进入和设置页「解绑设备」相同的 ⑦：K6 黄色快闪、K1 红色，
松开后再按 K6 确认，K1 取消，10 s 无操作自动取消。按住期间 K1、K6 黄色常亮；两键一起按下后，它们的单击 / 双击 / 长按、
菜单选项和对话框确认都不再生效，直到两键都松开。两键先后按下都可以：先按下的 K1 只会取消或返回，对话框只在松开 K6 时确认，
所以不会误触发。屏幕坏了也能完成：等 K6 开始黄色快闪，松开两键，再按一次 K6。没有 License 时只在状态栏提示
「未写 License，只能用 USB 配置」。固件升级进行中和硬件测试页里组合键无效。

**换 Wi-Fi 不用解绑**：已激活的键盘换网络时用「更换 Wi-Fi」+ USB Companion，或在「已保存的 Wi-Fi」里已有的网络之间自动切换；
「解绑设备」和 K1+K6 只在换账号或从头配网时用。涂鸦 App 的蓝牙「更换网络」目前不支持（TuyaOpen 只在未激活时启动蓝牙配网，
也没有实现已绑定设备的蓝牙改 Wi-Fi 命令）。

**排队**：不在 ① 时到达的请求不抢屏幕，先挂起；回到 ① 后自动弹出。挂起期间 K4 黄色呼吸
（在 ③ 时 K4 留给删字，只在状态栏提示有请求在等）。多个请求同时等待时，按
**系统确认 > 权限审批 > 提问 > 回复选项** 的顺序显示，同级按到达先后；屏幕标题栏显示排队位置（如 `1/3`）。

语音的「对话」模式下没有 ③：键盘直接和涂鸦云上的对话 agent 对话，回复留在键盘屏幕上，不发给 Kiro Crew。

**语音识别的两种来源**（在 Companion 里选）：

| 来源 | 说话时 | 松开后 |
|---|---|---|
| 键盘云端识别 | 键盘麦克风录音，经涂鸦云识别 | 识别出文字直接进 ③ |
| 电脑识别 | 电脑麦克风录音，Companion 用豆包、阿里云百炼或本地离线引擎识别；状态栏「正在听…」 | 键盘停在 ②，状态栏「识别中…」；结果到达后进 ③，状态栏绿色显示引擎名。没听清或失败时回 ①，状态栏橙色说明原因。等待中单击 K1 取消（「已取消输入」）；15 s 没有结果回 ①（「警告：语音识别超时」）。取消或超时后迟到的结果不会再进 ③ |

两种来源的文字都先在 ③ 确认，不会直接打进任何窗口。

## 5. 菜单（分页直选）

一个菜单每页最多 4 项，最多 12 页。菜单显示时键盘接管所有按键，**按下松开即生效**，不分单击 / 双击 / 长按；
菜单出现后的前 0.3 s 内按键无效，防止误选。

| 输入 | 单选菜单 | 多选菜单 |
|---|---|---|
| K2 / K3 / K4 / K5 | 直接选中当前页第 1–4 项（屏幕上标着对应键） | 勾选 / 取消当前页对应项 |
| 旋钮旋转 | 移动高亮，越过页尾 / 页首自动翻页 | 同左 |
| 旋钮按下 | 选中高亮项 | 勾选 / 取消高亮项 |
| K6 | 确认高亮项 | 提交全部勾选项 |
| K1 | ESC：关掉菜单，请求不作决定，之后可在 ① 单击 K4 找回 | 同左 |

- **权限审批菜单**：K6 和旋钮按下都无效，必须按选项对应的那个键（如 `Approve once`），防止误批。
- **需要二次确认的选项**（例如长期信任类）：第一次按下后该键黄色快闪，屏幕提示 `Press again to confirm`；
  3 s 内再按同一个键才生效，按别的键、转旋钮或超时则取消。
- **长内容**（diff、代码、长问题）不在键盘上显示，屏幕提示 `See screen`，到电脑上看。
- **口述回答**（紫色项 `Dictate answer`，只在支持云端语音时出现）：选中后按住语音键说出答案，确认页按 K6
  把文字作为答案发出，K1 回到菜单。

## 6. 灯光颜色

菜单显示时**只点亮当前能按的键**，其余熄灭；菜单关闭后恢复对话状态。

| 颜色 | 含义 |
|---|---|
| 蓝 | 可选择的普通选项 |
| 绿 | 确认 |
| 红 | 取消 / 拒绝；K1 的 ESC |
| 黄 | 注意。常亮：需要留意的选项；快闪：等待二次确认；呼吸：有对话在等你，或有被 ESC / 排队的请求（K4） |
| 紫 | 语音 / 口述回答 |

- 菜单里当前高亮项全亮度，其余项约 40% 亮度；LED7 显示旋钮按下会选中的那一项的颜色。
- 输入确认页（③）：K4 红色呼吸（删字 / 取消），K6 绿色闪烁（确认）。
- 设置页可以把灯光设为关 / 开 / 自动（空闲 30 s、1 min、5 min 或 15 min 后断电，按键、旋钮或菜单弹出时自动亮起）。

## 7. 设置页

旋钮长按进入。用旋钮操作（旋转选项或改值，按下进入或确认，选 Exit 退出）；子页另有按键，见各项说明。

下表每一项也能在 Companion 里查看和修改，两边以最后一次修改为准。凭证、配网窗口这类敏感项在 Companion 里
只能经 USB 操作，并且仍要在键盘上确认（K6 确认、K1 取消、10 s 无操作取消）；经蓝牙连接时 Companion 只显示状态。

| 项 | 说明 |
|---|---|
| 音量 / 亮度 | 10% 一档 |
| 语音模式 | 识别（文字确认后发给 Kiro Crew）/ 对话（与涂鸦云上的对话 agent 对话） |
| 灯光电源 | 关 / 开 / 自动；自动时空闲 30 s、1 min、5 min 或 15 min 后断电，有新活动（按键、旋钮、菜单弹出等）时自动亮起 |
| 界面语言 | 中文 / English；键盘屏幕和 Companion 界面都跟随 |
| 绑定会话 | 把一个 Kiro Crew 会话绑定到 K1–K3，见下 |
| 配网模式 / 更换 Wi-Fi | 未激活时叫「配网模式」：确认后重启进入 180 s 窗口，可用涂鸦 App 蓝牙配网，也可经 USB 写入 Wi-Fi、设备授权和蓝牙配对。已激活时叫「更换 Wi-Fi」：确认后立即打开 180 s 窗口（不重启），经 USB Companion 写入新 Wi-Fi 后直接上线，**涂鸦绑定不变**（devId、密钥不动），新网络也进「已保存的 Wi-Fi」 |
| 解绑设备 | 只用于换账号或从头配网。已激活：⑦ 确认后清除涂鸦绑定和 SDK 里当前那条 Wi-Fi（保留 License 和「已保存的 Wi-Fi」列表），重启进入 180 s 窗口，用涂鸦 App 蓝牙重新配网；未激活：同「配网模式」；无 License：只提示。也可用 K1+K6 组合键 |
| 已保存的 Wi-Fi | 列出键盘记住的网络（最多 10 个，正在用的标「当前」）。旋钮选择，K6 删除：第一次按 K6 后 K6 黄色快闪，3 s 内再按一次 K6 才删除；K1 返回。删除正在用的网络时，连接保持到断开为止，之后不再连它。新增网络只能经 USB |
| 凭证 | 查看设备授权和蓝牙配对状态；K6 允许覆盖一次设备授权，K1 连按两次清除蓝牙配对 |
| 测试 | 硬件自检 |

### 绑定会话

1. **选槽**：屏幕列出 A / B / C 和各自绑定的会话（没有就显示“未绑定”），K1–K3 亮蓝灯。按 K1 / K2 / K3 选槽；
   单击旋钮返回设置页；10 s 不操作也回设置页。
2. **选实例**：只有 Kiro Crew 里配置了远端实例（Remote Crews）时才出现。第一项是本机，后面是远端实例。
3. **选会话**：分页直选菜单（第 5 节）：K2–K5 选，旋钮翻页，K1 返回上一步。Bot（名字前带 `@`）排在最前，
   普通会话在后；Bot 派出的 worker 会话默认不列，可在 Companion 的控制页打开。最后一项“解除绑定”。
4. **完成**：所选槽的键灯绿色闪烁，回到设置页。

远端实例的会话目前只显示状态颜色（忙碌、等待操作、空闲）；单击该槽只提示“远端会话：仅显示状态”，
发消息和审批要在电脑上的 Kiro Crew 里做。
