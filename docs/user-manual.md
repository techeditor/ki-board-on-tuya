# Ki-board 使用手册

Ki-board 是面向 Kiro Crew 用户的 AI 键盘。它把 Kiro Crew 智能体的控制从屏幕搬到指尖：既是高效的提示词输入键盘（按住说话、在键盘上确认后发送），也是驱动智能体的物理入口（切换会话、审批、选择回复、换模型）。目前只支持 Kiro Crew。

本手册写给拿到键盘的用户：怎么装、怎么连、怎么用、出了问题怎么办，按键、灯光、菜单和屏幕上的规则也都在这里。开发者文档见[固件说明](../firmware/app/README.md)。

> 适用范围：固件 0.3 系列，Companion 为 Windows 版。本手册中的屏幕文字以中文界面为准；英文界面见[英文版](user-manual.en.md)。

## 1. 认识键盘

### 1.1 按键和旋钮

键盘有 6 个键（K1–K6）、1 个旋钮和 1 块屏幕。每个键下面有一盏灯，旋钮旁边还有一盏。

```text
  ┌──────────────────────────────────┐
  │ Ki-board v0.3.x   Wi-Fi USB 蓝牙 电池 │  顶栏
  ├────┬─────────────────────────────┤
  │ A  │                             │
  │ B  │      对话和状态显示区       │
  │ C  │                             │
  ├────┴─────────────────────────────┤
  │ 状态栏                           │
  └──────────────────────────────────┘
     K1   K2   K3        ( 旋钮 )
     K4   K5   K6
```

| 部件 | 默认作用 |
|---|---|
| K1 / K2 / K3 | 单击：选中对话 A / B / C，松手即生效。长按约 0.5 秒：切换到第 1 / 2 / 3 个 Kiro Crew（本机或远程）。两种操作都不动输入栏里的文字 |
| K4 | 输入栏有字：单击删最后一个字，长按清空。有被你关掉（ESC）的请求：单击把它重新调出来 |
| K5 | 语音键：按住说话，松开结束 |
| K6 | 单击：发送输入栏里的文字（输入栏有字或电脑已填入时才有效）。双击：在 Auto 和上次手选的模型之间切换。长按：打开模型 / 权限模式菜单 |
| 旋钮 | 转动：在电脑的 Kiro Crew 窗口里上下滚动。单击：在电脑上按一次回车。长按：打开设置页 |

普通键和旋钮按下认识三种手势：

| 手势 | 怎么按 |
|---|---|
| 单击 | 按一下就松开。**如果这个键没有设置双击，松手立刻生效**。设了双击的键（默认的 K6）要多等 0.25 秒，确认你没有再按第二下 |
| 双击 | 松手后 0.25 秒内再按一下并松开 |
| 长按 | 按住到时间就立即生效，不用等松开。K1–K3 是 0.5 秒，其他键和旋钮是 0.8 秒 |

一次操作只算一种手势。K1–K3 长按到 0.5 秒时，该键灯变蓝，状态栏显示「切换到实例 N」，同时切换。不到 0.5 秒松开只算单击，不会再切换。

K5 不分手势：按下开始说话，松开结束。请**按住不放**，说完再松开。

除了旋钮长按（固定打开设置页），其他键的功能可以在 Companion 的「按键映射」里修改。三个对话槽的显示名（默认 A / B / C）也可以在 Companion 里设置。

### 1.2 屏幕

- **开机画面**：开机时先显示开机画面，默认约 1.5 秒；装了定制开机画面的键盘显示约 4 秒。按任意键或转动旋钮可以立即跳过，这次按键不会触发任何功能。
- **顶栏**：左边是「Ki-board」和固件版本号。右边依次是 Wi-Fi、USB、蓝牙图标和电池。Companion 已连接时顶栏是紫色，没连接时是黑色。
- **左侧三张卡片**：对应 K1–K3 绑定的三个对话 A / B / C。选中的卡片是紫色。卡片右上角的小圆点表示对话状态：

  | 圆点 | 状态 |
  |---|---|
  | 深灰 | 未绑定 |
  | 绿 | 空闲 |
  | 红 | 忙碌 |
  | 橙 | 在等你操作 |
  | 浅紫 | 有新信息，不需要你操作 |

- **状态栏**：屏幕最下面一行，显示当前提示，例如「Wi-Fi 已连接」「正在听…」。错误是红字，警告是黄字，成功是绿字。
  - 开机连已保存的 Wi-Fi、或断线后自动重连期间，显示「连接 Wi-Fi…」，连上后显示「Wi-Fi 已连接」。
  - 30 秒还没连上（又没有换到别的已保存网络），改显示「警告：Wi-Fi 已断开」。键盘仍在后台继续重试。
  - 蓝牙配对窗口打开时，状态栏保持配对提示，不会被 Wi-Fi 状态盖住；窗口关闭后再显示 Wi-Fi 状态。

### 1.3 灯光颜色

弹出菜单时，**只有当前能按的键亮灯**，其余熄灭。菜单关闭后恢复成对话状态。

| 颜色 | 含义 |
|---|---|
| 蓝 | 可以选择的普通选项 |
| 绿 | 确认 |
| 红 | 取消、拒绝；K1 的红灯是「返回 / ESC」 |
| 黄 | 注意。常亮：需要留意的选项；快闪：等你再按一次确认；呼吸：有对话在等你，或有被关掉的请求（K4） |
| 紫 | 语音相关 |

另外：

- K1–K3 黄色呼吸，表示对应的对话在等你操作。
- 输入栏有字或电脑已填入文字时：K4 红色呼吸（删字），K6 绿色闪烁（发送）。
- 菜单里当前高亮的项全亮度，其余项约 40% 亮度。旋钮旁的灯显示「按下旋钮会选中的那一项」的颜色。
- 灯光可以在设置页里设为「关」「常开」「自动」。默认是「自动」，空闲 60 秒后熄灭，按任意键或旋钮会重新亮起。自动模式可选 30 秒、60 秒、5 分钟或 15 分钟。

### 1.4 电源和电池

- 键盘内置锂电池。用键盘**左侧**（开发板上）的拨动开关开机，也可以用 USB 线接电脑或充电器供电和充电。
- 顶栏右上角的电池图标显示电量百分比。电量低于 20% 时，电池填充变红。
- 电量是根据电池电压估算的，不是精确值。插上或拔掉充电线的瞬间，数字可能重新校准，跳一下属于正常。
- 电量不高于 15% 时，对话卡片上的小动画会暂停，接上充电线后恢复。

### 1.5 键盘的工作状态

键盘任何时刻处在下面一个状态。

| 状态 | 什么时候进入 | 怎么离开 |
|---|---|---|
| 待命 | 开机；其他状态结束后 | 按住 K5 开始说话；有请求到来；K6 长按；旋钮长按 |
| 语音输入 | 按住 K5 | 识别出文字后回待命（文字进输入栏）；没识别出、失败或超时也回待命 |
| 口述回答确认 | 在菜单里选了「语音回答」并说完 | K6 发送；K1 或 20 秒不操作回到菜单 |
| 菜单 | 权限审批、提问、回复选项到来 | 选中、ESC（K1）、请求已在别处处理、超时 |
| 模型 / 权限模式菜单 | 长按 K6 | 同上 |
| 设置 / 测试 | 长按旋钮 | 选「退出」 |
| 系统确认 | 打开配网窗口或更换 Wi-Fi、解绑设备、重置系统、清除蓝牙配对、蓝牙配对比对码、固件升级 | 确认、取消，或 10 秒不操作（比对码是 30 秒） |

**谁盖住谁**：系统确认盖住一切，其次是设置页，再其次是其余状态。

系统确认的按法：**松开 K6 才算确认**（按下不算），K1 取消。默认停在「取消」，防止误触。

## 2. 开箱上手

### 2.1 你需要准备

- 一台 Windows 电脑，已安装并运行 Kiro Crew。
- 键盘自带的 USB 线（要能传数据，只能充电的线不行）。
- 一个 **2.4 GHz** 的 Wi-Fi。键盘不能连 5 GHz。
- 手机上的涂鸦 App（涂鸦智能或 SmartLife），用于首次绑定。
- 一个涂鸦 IoT 平台上的产品（取得 Tuya PID），以及这台键盘用的 Tuya UUID 和 AuthKey。只用键盘控制 Kiro Crew 时不需要，见 2.5。

不联网时，键盘和 Companion 仍然可以控制 Kiro Crew。联网后才能用键盘自带的云端语音识别和「对话」语音模式。

### 2.2 获得 Companion 和固件

目前**不提供预编译的 Companion 和固件**（还不够稳定）。请按仓库 README 从源码构建：

- 固件：见 [`firmware/app/README.md`](../firmware/app/README.md) 的 Build 和 Flash 两节。请用 release 配置（`TUYA_T5AI_CORE_dual_cloudasr`）构建。debug 配置只用于开发，不要用在日常使用的键盘上。
- Companion（Windows 版）：见仓库根目录 [`README.md`](../README.md) 的 Build 一节。

固件烧录前先关掉 Companion，它会占用串口。

### 2.3 连接键盘

**用 USB 连接（最简单，首次必须这样）**

1. 用 USB 线把键盘接到电脑。
2. 打开 Companion。它默认「自动连接」，会找到键盘并连上。
3. 右上角显示「在线 · USB」，同时键盘顶栏变紫，状态栏显示「Companion 已通过 USB 连接」。

**用蓝牙连接（脱线使用）**

蓝牙要先和这台电脑配对一次。**不需要 USB，也不需要先绑定涂鸦**，直接用蓝牙配对：

1. 电脑打开蓝牙。在 Companion 的「连接」页，传输方式选「自动」或「BLE」，点「扫描」，选中你的键盘。蓝牙名字是 `Ki-board-XXXXXX`，后 6 位是键盘 Wi-Fi MAC 地址的后 6 位，可以在键盘「设置 → 设备信息」里核对。
2. 在键盘上长按旋钮进入设置，选「蓝牙配对」，单击旋钮。设置项显示「已打开 m:ss」，窗口 120 秒。
3. 回到 Companion，点蓝牙设备下面的「蓝牙配对」。键盘弹出「蓝牙配对？」，显示一个 6 位比对码，Companion 也显示一个。
4. **核对两个比对码是否一样。** 一样就在 Companion 点「一致」，并在键盘上按 **K6**。不一样或不是你在操作，按键盘 K1 取消。30 秒不操作也会取消。
5. 键盘提示「已与此 Companion 蓝牙配对」。点「连接」就可以用蓝牙了，之后不用再配对。

注意：

- 一个窗口只能配对一次，失败 3 次窗口自动关闭。要再配，重新在键盘上打开。
- 新的配对会替换旧的。之前配对过的电脑要重新配对。
- 窗口没打开时点「蓝牙配对」，键盘不会有反应，Companion 会提示先在键盘上打开「设置 → 蓝牙配对」。
- 也可以接 USB 配对：先在键盘上打开「配网模式」窗口（见 6.3），再到 Companion「高级设置」的「蓝牙配对」点「配对」。

自动连接的顺序是：先找 USB，找不到再连已配对的蓝牙键盘。断线后会自动重连（间隔 2、4、8、16 秒，之后每 30 秒一次）。你手动点了「断开」后不会自动重连，要再点「连接」或重启 Companion。

键盘没绑定涂鸦时也会开蓝牙。只有「配网模式」的 180 秒窗口开着时，蓝牙留给涂鸦 App 配网，Companion 暂时连不上，窗口关闭后恢复。USB 连着时键盘优先走 USB。

### 2.4 与 Kiro Crew 连接

1. 先打开并登录 Kiro Crew，让它保持运行。
2. Companion 会自动连接本机的 Kiro Crew：经 Kiro Crew 的本机接口（只走本机回环）读取对话状态、发送提示词和审批回复，连接前先确认对方是你自己用户下运行的 Kiro Crew。在「控制」页能看到「实时连接」显示「已连接」和对话列表。
3. 在「输入」页确认「板子按键驱动 Kiro Crew」是「开」。关闭时，键盘按键不会在电脑上做任何事。

如果 Companion 提示「Crew 身份校验失败」，见[常见问题](#companion-显示crew-身份校验失败)。

### 2.5 写入 Tuya PID 和 UUID/AuthKey（用涂鸦云前必须）

新键盘出厂时**没有**写入 Tuya PID（产品 ID）、Tuya UUID 和 Tuya AuthKey。没有它们，涂鸦云是关的：状态栏提示「未设置产品 ID：用 USB 写入」，云端语音识别和「对话」模式不能用。键盘本身、屏幕、Companion（USB 和蓝牙）和电脑识别语音都不受影响。只用键盘控制 Kiro Crew 的话，这一节可以跳过。

要用涂鸦云，先经 USB 写入它们（只能经 USB，蓝牙不行）。UUID 和 AuthKey 是这台设备自己的授权信息，请妥善保管，不要发给别人，也不要贴到 Issue 里。下面的步骤里用 `<…>` 表示你自己的值：

1. 用 USB 连接键盘和 Companion。
2. **写 PID**：Companion「高级设置」页，找到「Tuya PID / UUID / AuthKey」卡片，在「涂鸦 PID」里填 `<你的 Tuya PID>`（16 位小写字母和数字，来自你在涂鸦 IoT 平台上创建的产品），点「写入 PID」。键盘只在**还没有 PID** 时接受它，写入后要**重启键盘**才生效（状态栏会提示）。
3. **打开配网窗口**：在键盘上长按旋钮进入设置，选「配网模式」，按 K6 确认。没有 Tuya UUID/AuthKey 的键盘会立即打开 180 秒窗口。
4. **写 UUID 和 AuthKey**：窗口开着的时候，在同一张卡片里填 `<你的 Tuya UUID>`（20 位）和 `<你的 Tuya AuthKey>`（32 位），点「写入 Tuya UUID/AuthKey」。键盘提示「Tuya UUID/AuthKey 已保存：重启后生效」。重启键盘。
5. 到「设置 → 设备信息」，设备组里的 Tuya PID、Tuya UUID、Tuya AuthKey 都显示「已设置」，就写好了。屏幕不会显示具体的值。
6. 接着按 2.6 联网并绑定涂鸦。

注意：

- 键盘已经有 Tuya UUID/AuthKey 时，再写新的会被拒绝，提示「已有 Tuya UUID/AuthKey：请先允许覆盖」。要换的话，窗口开着时在「设置 → 设备信息」按 K6 允许覆盖一次（60 秒内有效）。
- PID 只能写一次，也不能在键盘上修改。要换 PID，先用「设置 → 重置系统」清除（见第 4 节），再重新写。
- **「重置系统」会把 Tuya PID、UUID 和 AuthKey 一起清掉**，之后涂鸦云又关了，必须按本节重新写入。解绑设备和 K1+K6 恢复组合键不会清掉它们。

### 2.6 联网并绑定涂鸦

键盘需要先写好 Tuya PID 和 UUID/AuthKey（2.5），再绑定涂鸦，才能用云端语音识别和「对话」模式。有两种方式，任选一种。键盘只能连 2.4 GHz Wi-Fi。

**方式一：涂鸦 App 蓝牙配网（不需要电脑）**

1. 在键盘上按住旋钮进入设置，选「配网模式」，按 K6 确认。键盘重启后进入 180 秒的配网窗口，状态栏显示「配网模式：请用涂鸦 App」。
2. 手机打开蓝牙，打开涂鸦 App，选「添加设备」，在附近设备里找到键盘并按提示操作，填入 2.4 GHz Wi-Fi 的名称和密码。
3. 屏幕显示「配网完成」，键盘就绑定好了。

**方式二：用 USB 和 Companion 配网**

1. 用 USB 连接 Companion，在键盘上进入设置，选「配网模式」，按 K6 确认。
2. 在 Companion 的「连接」页，找到「Wi-Fi 与 SmartLife」，填入 Wi-Fi 名称（2.4 GHz）和密码，点「发送到键盘」。
3. 键盘连上 Wi-Fi 后，Companion 会显示一个二维码。用手机上的涂鸦 App 扫一扫，完成绑定。

键盘每次成功连上的 Wi-Fi 都会被记住，包括用涂鸦 App 配网的那个。详见[第 6 节](#6-wi-fi-与配网)。

> 如果状态栏提示「未写 Tuya UUID/AuthKey，只能用 USB 配置」或「未设置产品 ID：用 USB 写入」，说明还没有按 2.5 写入。

不用涂鸦云也可以使用键盘（控制 Kiro Crew、电脑识别语音、蓝牙连接），不需要绑定。设置页里「设备信息」的 Tuya PID、Tuya UUID、Tuya AuthKey 三项只给涂鸦云用，不用涂鸦云可以不管。

## 3. 日常使用

### 3.1 切换会话

键盘屏幕左侧的 A / B / C 三张卡片对应三个 Kiro Crew 会话。

| 操作 | 效果 |
|---|---|
| 单击 K1 / K2 / K3 | 选中对话 A / B / C，松手即生效。之后语音输入的文字会发到这个对话 |
| 长按 K1 / K2 / K3（约 0.5 秒） | 切换到第 1 / 2 / 3 个 Kiro Crew（本机，或你配置的远程 Kiro Crew）。该键灯变蓝，状态栏显示「切换到实例 N」 |

输入栏里有文字时，这两个操作都不会动文字。

单击后，Companion 默认会把 Kiro Crew 窗口拉到前台。不想这样，可以在 Companion「输入」页关掉「用 K1–K3 选对话时把 Kiro Crew 窗口拉到前台」。

### 3.2 绑定会话

要让 K1–K3 对应你想要的会话，先绑定：

1. 长按旋钮进入设置，选「绑定会话」。
2. 屏幕列出 A / B / C 三个槽，K1–K3 亮蓝灯。按 K1 / K2 / K3 选一个槽。
3. 如果你配置了远程 Kiro Crew，先选「本机」或某个远程实例。
4. 在会话列表里用 K2–K5 直接选，旋钮翻页，K1 返回上一步。Bot（名字前带 `@`）排在最前面，然后是普通会话。最后一项「解除绑定」用来清空这个槽。
5. 绑定成功后，这个槽的键灯绿色闪烁，回到设置页。

也可以在 Companion 的「控制」页「A / B / C 键」里选。Bot 派出的 worker 会话默认不列出，需要时在 Companion「输入」页打开「键盘上绑定会话时列出 worker 会话」。

远程 Kiro Crew 的会话只显示状态颜色。单击这个槽会提示「远端会话：仅显示状态」，发消息和审批要在电脑上的 Kiro Crew 里做。

### 3.3 语音输入

1. 按住 **K5** 说话，状态栏显示「正在听…」。
2. 说完松开。键盘显示「识别中…」，几秒内识别出的文字出现在屏幕底部的**输入栏**里。
3. 看一眼文字，对就按 **K6** 发送。

文字不会自动发送，必须你按 K6。

**输入栏**

- 在屏幕底部、状态栏上方。默认 2 行，文字更长时 3 行，再长就用旋钮滚动（右边有细滚动条）。12、14、16 号字都放得下。
- 只在末尾编辑，没有光标。再按住 K5 说话，新文字接在末尾（两边都是英文或数字时自动补一个空格）。
- **K4 单击**删最后一个字，**K4 长按**清空，删光后输入栏自动关闭。**K6 单击**发送。输入栏没有单独的「取消」键，要放弃就长按 K4 清空。
- K1–K3 的含义不变：单击切到对应对话，输入栏里的文字不动。录完发现选错了对话，直接换一个再按 K6。长按 K1–K3 切换 Kiro Crew 时文字也保留。
- 没有超时，文字一直留到你发送或清空。上限约 126 个汉字或 380 个英文字符，放满后多的字不再记录，状态栏会提示「输入栏已满，多的字没有记下」。
- 发送失败（Kiro Crew 没开、没登录、这个键没有绑定对话）：文字留在输入栏，状态栏用红字写原因，可以再按 K6，状态栏显示「未发送：K6 重发」。键盘没连上 Companion 时同样不发送，文字保留，提示「未连接 Companion，文字已保留」。
- 菜单到来时马上弹出，输入栏的文字保留，菜单结束后重新显示。设置页和系统确认也不会丢文字。

**文字发到哪里**

每个对话槽有自己的去处，不用手动切换：

| 去处 | 哪个槽用 | 文字去哪 | 怎么发送 |
|---|---|---|---|
| 键盘输入栏（默认） | 没设 Alt+N 数字的槽，或 Companion「输入」页「语音文字」选了「所有对话都用键盘模式」 | 键盘输入栏 | K6：经 Kiro Crew 接口发到 K1–K3 选中的对话。不管电脑上开着哪个对话，也不用 Kiro Crew 窗口在前台 |
| 电脑输入框 | 设了 Alt+N 数字，且 Companion 的「键盘控制电脑」打开、Kiro Crew 窗口可用 | Companion 切到那个对话，把文字打进 Kiro Crew 的输入框，不发送。键盘不换页，状态栏显示「已填入输入框：K6 发送 / K4 清空」 | K6，或在电脑上按 Enter。K4 删字，长按 K4 清空输入框。20 秒内有效，中途选了别的对话就失效 |

电脑输入框这条路的前提不满足时（键盘控制电脑关了、Kiro Crew 窗口不在前台、打字失败），文字会自动改放进键盘输入栏，状态栏说明原因。Alt+N 数字在 Companion「控制」页设置。

**两种识别方式**（Companion「输入」页「语音识别」里选）：

| 方式 | 录音 | 说明 |
|---|---|---|
| 键盘云端识别（涂鸦） | 键盘麦克风 | 需要键盘连上 Wi-Fi 并写好 Tuya UUID/AuthKey、已绑定涂鸦。识别出的文字直接进输入栏 |
| 电脑识别 | 电脑麦克风 | 引擎可选豆包、阿里云百炼或本地离线。豆包和阿里云需要你自己的 API Key；本地离线需要先下载模型（约 245 MB）。松开后键盘停在「识别中…」，结果到达后进输入栏，状态栏用绿色显示引擎名，例如「电脑识别:本地」 |

电脑识别的几个细节：

- 等结果时，**单击 K1 取消**，状态栏显示「已取消输入」。15 秒没有结果会自动回到待命，显示「警告：语音识别超时」。取消或超时之后迟到的结果不会再出现。
- 没听清或失败时，状态栏用橙色写原因。
- 选了「电脑识别」后，如果在线引擎没有 Key 或连不上，Companion 可以自动改用本地离线识别（勾选「云端失败或没有 Key 时，自动改用本地离线识别」，需要已下载本地模型）。

**键盘云端识别用不了时，自动改用电脑识别**：没有 Tuya UUID/AuthKey、没激活或没配网、配网窗口开着、Wi-Fi 或涂鸦云没连上，这些情况下键盘自己的云端识别都用不了。只要 Companion 连着（USB 或已认证的蓝牙），按住 K5 就直接走电脑识别。Companion 没连上时，按住 K5 只会提示「语音需要连接 Companion 或完成配网」，不会录音。Companion 开着但「键盘控制电脑」关了，提示「语音需要打开键盘控制电脑」。

**两种语音模式**（设置页「语音模式」，或 Companion「设备设置」页「键盘设置」里切换）：

- 「语音输入」：识别出的文字进输入栏，由你发给 Kiro Crew。这是默认模式。
- 「对话」：和涂鸦云上的对话助手聊天，回复显示在键盘屏幕上并播放出来，不会发给 Kiro Crew。没有输入栏。需要键盘已联网并绑定涂鸦。涂鸦云暂时用不了时，按住 K5 这一次会按「语音输入」处理，状态栏提示「云不可用：本次按语音输入」，云恢复后自动回到对话模式，设置里保存的语音模式不变。

状态栏上和语音有关的提示（正在听、识别中、识别来源、已取消输入等）会盖住常驻的「配网模式」「改用 PC ASR」提示，显示约 4 秒后恢复。

### 3.4 审批、提问和回复选项

Kiro Crew 需要你做决定时，键盘会弹出菜单并接管按键。你可以不碰电脑，直接在键盘上选。

**怎么选**：

| 输入 | 单选菜单 | 多选菜单 |
|---|---|---|
| K2 / K3 / K4 / K5 | 直接选当前页的第 1–4 项（屏幕上标着对应的键） | 勾选 / 取消勾选对应项 |
| 旋钮转动 | 移动高亮，到页尾自动翻页 | 同左 |
| 旋钮按下 | 选中高亮项 | 勾选 / 取消勾选高亮项 |
| K6 | 确认高亮项 | 提交全部勾选项 |
| K1 | ESC：关掉菜单，不做决定 | 同左 |

菜单刚出现的 0.3 秒内按键无效，防止误按。

**几种菜单**：

- **权限审批**：选项是「批准一次」「拒绝」「本次拒绝」。智能体常常一次提出好几个工具调用（一批）。「拒绝」会拒绝这一个调用，同时拒绝同一批里还在等待的其他调用，并告诉智能体你拒绝了。「本次拒绝」只拒绝这一个，同一批的其他调用照常继续（需要批准的仍会再问你）。两种拒绝都不会被记住，下次再有请求仍会询问。**K6 和旋钮按下在审批菜单里不起作用**，必须按选项对应的那个键，防止手滑批准。
- **提问和回复选项**：选项就是 Kiro Crew 给出的答案。有紫色的「语音回答」项时（只在用键盘云端识别时出现），选中后按住 K5 说出答案，说完后进入确认页：按 **K6** 把文字作为答案发出，按 K1 或 20 秒不操作回到菜单。
- **需要二次确认的选项**（例如权限模式里的「信任」）：第一次按后，该键黄色快闪，屏幕提示「再按一次确认」。3 秒内再按同一个键才生效。按别的键、转旋钮或超时都会取消。
- **长内容**（代码改动、长问题）不在键盘上显示，屏幕提示「详见电脑屏幕」，请到电脑上看。

**被关掉的请求**：按 K1 关掉菜单后，请求还在，只是你没有做决定。回到待命状态后，K4 会黄色呼吸，单击 K4 重新弹出。

**排队**：在你正说话或等识别结果、或在口述回答确认页时到来的请求，不会抢屏幕，先排队，结束后自动弹出，排队期间 K4 黄色呼吸。输入栏不挡请求：请求到来时马上弹出，输入栏的文字保留，处理完后输入栏重新显示。屏幕标题栏会显示排队位置，例如 `1/3`。多个请求同时在等时，按「系统确认、权限审批、提问、回复选项」的顺序依次显示，同级按到来先后。

### 3.5 切换模型和权限模式

- **双击 K6**：在 Auto 和你上次手动选的模型之间来回切换。没手动选过模型时会提示「还没有选过模型」。
- **长按 K6**：为当前选中的对话打开一个菜单。可用模型排在前面几页，权限模式在最后一页，当前生效的项打勾。
  - 如果这个对话正忙，换模型后会提示「模型：下一轮生效」。
  - 权限模式有三个：「正常」「读取免批」「信任」。选「信任」要按两次确认。
  - 键盘上不能设置更宽松的模式，那只能在 Kiro Crew 里设置。

### 3.6 旋钮

| 操作 | 作用 |
|---|---|
| 转动 | 在电脑上的 Kiro Crew 窗口里上下滚动（顺时针向下）。有菜单时移动高亮 |
| 单击 | 在电脑上按一次回车 |
| 长按 | 打开设置页 |

「对话」语音模式下，转旋钮滚动键盘屏幕上的对话。屏幕放不下的长文字也用旋钮逐行滚动：顺时针一格向下一行，逆时针向上一行，右边有一条细滚动条（文字放得下时不显示）。已经在顶部还往上转，状态栏短暂显示「已到顶部」；在底部还往下转，显示「已到底部」。键盘没有振动马达，不会震动。

不同界面里旋钮转动的作用：

| 界面 | 旋钮转动 |
|---|---|
| 「对话」模式的对话页 | 滚动对话。看着最新一行时，回复变长会自动跟到最新。往上翻过以后，新内容到达时画面不动，标题行右侧显示「有新内容」，转回到底部后提示消失。新的一轮对话从最新一行开始 |
| 待命，输入栏有字 | 文字超过输入栏高度时滚动输入栏，停在末尾。没超过时和下一行一样 |
| 口述回答确认 | 文字超过一屏时滚动文字，从第一行开始。没超过一屏时不动 |
| 待命（语音输入模式） | 在电脑上滚动。屏幕上的历史只显示最新几行 |
| 菜单 | 移动高亮，越过页尾翻页。提问和回复选项的说明最多 3 行，放不下的显示 `...`，长内容提示「详见电脑屏幕」 |
| 设置页、已保存的 Wi-Fi | 移动选择，列表随选择滚动，右边有滚动条 |

不同字号下一屏的行数不同，滚动按当前字号的行计算。改字号后对话页回到最新一行。

## 4. 键盘设置页

**打开**：长按旋钮。**操作**：转旋钮选项，单击旋钮进入或确认，选「退出」离开。数值类设置单击后进入编辑，转旋钮改值，再单击确认，屏幕显示「已应用」。

设置页从上到下是：

| 项 | 说明 |
|---|---|
| 音量 | 10% 一档 |
| 屏幕亮度 | 10% 一档 |
| 语音模式 | 「语音输入」或「对话」，见 3.3 |
| 灯光电源 | 「关」「常开」「自动」。默认「自动」 |
| 灯光自动关闭 | 只在「自动」时有效。空闲 30 秒、60 秒、5 分钟或 15 分钟后熄灯，有按键、旋钮或菜单时自动亮起。默认 60 秒 |
| 语言 | 中文或 English。键盘屏幕和 Companion 界面都会跟着改 |
| 字号 | 12、14 或 16 px，默认 12 px。看不清就改大 |
| 动画 | 开或关。控制对话卡片上的小幽灵动画 |
| 场景 | 单击打开场景选择，右边显示当前场景名，名字后带 `*` 表示应用场景后你又改过语音模式或灯光。场景是一组按键功能、语音模式和灯光设置，在 Companion 的「场景」页里编辑 |
| 绑定会话 | 把 Kiro Crew 会话绑到 K1–K3，见 3.2 |
| 已保存的 Wi-Fi | 键盘记住的 Wi-Fi 列表，见下 |
| 设备信息 | 只读，键盘当前的连接、Wi-Fi、蓝牙和设备状态，见下 |
| 蓝牙配对 | 打开 120 秒窗口，不接 USB 就能和电脑蓝牙配对，见 2.3 |
| 配网模式 / 更换 Wi-Fi | 没绑定涂鸦时叫「配网模式」，已绑定后叫「更换 Wi-Fi」，见[第 6 节](#6-wi-fi-与配网) |
| 解绑设备 | 清除涂鸦绑定，见[第 6 节](#6-wi-fi-与配网)。**只在键盘已绑定涂鸦后才出现**。没绑定时设置里没有这一项，要配网请用「配网模式」 |
| 重置系统 | 把键盘恢复成一块新板子：设置恢复默认，并清除已保存的 Wi-Fi、涂鸦激活、Tuya PID/UUID/AuthKey 和蓝牙配对。要按两次 K6 确认，见下 |
| 硬件测试 | 检查按键、旋钮、灯、电池、Wi-Fi 和蓝牙。按页面提示操作，双击旋钮退出 |
| 退出 | 回到待命 |

**重置系统**

用在送人、转让、或想让键盘回到刚拿到手的状态时。

1. 在设置里选中「重置系统」，底部会提示要清除什么。单击旋钮。
2. 弹出第一个红色确认框「重置系统？」，列出会发生的事：
   - **恢复默认**：音量、屏幕亮度、灯光、语音模式、语言、字号、动画、按键绑定和场景。
   - **清除**：已保存的 Wi-Fi、涂鸦激活、Tuya PID（产品 ID）/ UUID / AuthKey、蓝牙配对、Companion 配对。
3. 按 **K6** 继续，按 K1 取消。弹出第二个红色确认框「确认清除以下全部内容？」，再按一次 **K6**「重置」才真正执行。每个框 10 秒不操作都算取消，任何一步取消都不会改动任何东西。
4. 屏幕显示「正在重置系统，即将重启…」，键盘重启。

要知道的事：

- 键盘已激活并在线时，会先在涂鸦云端解绑。**离线时只清键盘本地**，涂鸦 App 里的旧设备需要你在 App 里手动删除。
- 重置后 Tuya PID、UUID、AuthKey 都没了，涂鸦云是关的，要用时按 2.5 重新写入。
- 蓝牙配对被清除，Companion 要重新配对：用「设置 → 蓝牙配对」，或接 USB（见 2.3）。
- 固件版本的防降级记录会保留，不会因为重置而允许装回旧版本。
- 只想换 Wi-Fi 或换涂鸦账号，不需要重置系统，见第 6 节。

**已保存的 Wi-Fi**

- 列出键盘记住的网络，正在用的标「当前」，标题显示已存数量，例如 `3/8`。
- 转旋钮选择，按 **K6 删除**。第一次按 K6 后 K6 黄色快闪，3 秒内再按一次才真的删除。K1 返回。
- 删除正在用的网络：连接保持到断开为止，之后不再连它。
- 新增网络只能经 USB（见第 6 节）。

**设备信息**

- 只读页面，分四组：**连接**（Companion 是 USB、蓝牙还是未连接，是否已握手；涂鸦云是已激活、未激活还是离线）、**Wi-Fi**（名称、IP 地址、信号强度、Wi-Fi MAC）、**蓝牙**（蓝牙 MAC、蓝牙名字、配对状态）、**设备**（固件版本、Tuya PID、Tuya UUID、Tuya AuthKey）。
- 内容比一屏长，转旋钮上下翻，右边有滚动条。状态变化时自动刷新。K4 或单击旋钮返回。
- 没连 Wi-Fi 时，名称、IP 和信号显示 `--`，这是正常的。Wi-Fi MAC 和蓝牙 MAC 仍会显示。
- Tuya PID、UUID、AuthKey 只显示「已设置」或「未设置」，屏幕不会显示具体内容。它们只给涂鸦云用，不用涂鸦云可以不管。蓝牙配对密钥同样不显示。
- **连按两次 K1** 清除蓝牙配对（已配对时）。清除后需要重新配对。
- 打开「配网模式」窗口、并且键盘已有 Tuya UUID/AuthKey 时，按 K6 可以允许覆盖一次（60 秒内有效）。一般用不到。

Companion 的「设备设置」页里「键盘设置」有一份相同的设置（语音模式、按键灯光、自动关灯时间、屏幕字号、对话图标动画），音量和亮度在上面的「音量与亮度」，下面的「设备信息」和键盘上的内容一致。用 USB 或已配对的蓝牙都能改，键盘和 Companion 以最后一次修改为准。

## 5. Companion 说明

> 本节描述 Companion 的新版界面（单列布局，自动连接 USB 后蓝牙）。旧版界面的按钮位置不同。

Companion 目前只有 Windows 版。打开后窗口上方是：

- 「Ki-board」和「Kiro Crew 伴侣」标题。
- 在线状态，例如「在线 · USB」或「离线」。
- 「简约」和「进阶」两个模式。
- 右上角齿轮：切换主题和界面语言。

### 简约模式

只有这几件事：连接 / 断开键盘、当前语音模式、正在关注的对话、场景快速切换。日常用这个就够了。

### 进阶模式

左边有七个页面：

| 页面 | 里面有什么 |
|---|---|
| 连接 | 传输方式（自动 / USB / BLE、设备端口、蓝牙设备扫描、自动连接）；选了蓝牙后，设备下面有「蓝牙配对」（不接 USB 配对，见 2.3）；配网窗口；「Wi-Fi 与 SmartLife」；已保存的 Wi-Fi |
| 输入 | 「板子按键驱动 Kiro Crew」总开关；语音文字去向；语音识别方式、引擎、API Key、本地模型、热词；按键映射 |
| 场景 | 场景列表、新建、切换、导入导出，以及键盘上的常用场景 |
| 控制 | Kiro Crew 连接状态和对话列表；「A / B / C 键」绑定；关注的对话。底部的「旧快捷键方式」（向 Kiro Crew 窗口注入按键，并用 Kiro Crew 的状态 hook 显示状态）只在连不上 Kiro Crew 的本机接口时当后备用，一般不用 |
| 设备设置 | 音量与亮度；键盘设置；「设备信息」（和键盘上的设备信息页一致，可以复制） |
| 高级设置 | 蓝牙配对（经 USB）；Tuya PID、UUID、AuthKey 写入；解绑设备；固件升级。很少用到 |
| 日志 | 键盘和 Companion 之间的事件流，排查问题时看 |

**哪些操作必须用 USB**：写入 Wi-Fi、写入 Tuya PID 和 UUID/AuthKey、打开配网窗口、经 USB 的蓝牙配对和清除、解绑设备、删除已保存的 Wi-Fi、固件升级。（不接 USB 的蓝牙配对例外，它在键盘上用比对码确认。）这些页面里的按钮在蓝牙连接下是灰的，只显示状态。其中打开配网窗口、解绑设备、清除键盘上的蓝牙配对和固件升级，还要在键盘上按 K6 确认。

## 6. Wi-Fi 与配网

### 6.1 键盘怎么记 Wi-Fi

- 键盘最多记住 **8 个** Wi-Fi。成功连上并拿到网络地址后才会记住。
- 用涂鸦 App 配网时连的那个热点，也会记住。
- 存满后，再连新网络会覆盖**最久没连过**的一个。
- 断线后键盘会扫描周围，连上信号最强的已保存网络。到了去过的地方，不用做任何事。
- 密码只存在键盘里，Companion 和屏幕上都看不到。
- 只支持 2.4 GHz。

### 6.2 换 Wi-Fi 环境，三条路

| 情况 | 做法 | 涂鸦绑定 |
|---|---|---|
| ① 回到连过的地方 | 什么都不用做。键盘自动记住连接过的 Wi-Fi，回到那里自动重连 | 不变 |
| ② 有电脑和 USB 线 | 接 USB，键盘上「设置 → 更换 Wi-Fi」，按 K6 确认。在 Companion「连接」页「Wi-Fi 与 SmartLife」填新 Wi-Fi，点「发送到键盘」，键盘立即上线，不用重启 | **不变** |
| ③ 没有 USB | 键盘上「设置 → 解绑设备」，按 K6 确认，重启后用涂鸦 App 蓝牙配网 | **原绑定丢失**，要在涂鸦 App 里重新添加 |

**做法 ① 不需要操作**：键盘最多记住 8 个连接过的 Wi-Fi，存满后覆盖最久没连过的，用涂鸦 App 配网的那个也算。回到连过的地方，断线后它会自动重连。

**做法 ② 的步骤**：见上表。「更换 Wi-Fi」确认框里写着「绑定不变」，窗口 180 秒内有效。如果新 Wi-Fi 连不上，键盘会提示「Wi-Fi 失败，已恢复原网络」。

**做法 ③ 才需要解绑**，而且键盘要已经绑定过涂鸦。「解绑设备」会清除涂鸦绑定和当前 Wi-Fi，保留 Tuya UUID/AuthKey 和已保存的 Wi-Fi 列表，然后重启进入配网窗口。它也用于**换涂鸦账号**或从头配网。没绑定过涂鸦的新键盘，设置里没有「解绑设备」，直接用「配网模式」。

**解绑后重新配网的步骤**：

1. 键盘设置页选「解绑设备」（或同时按住 K1 + K6 约 5 秒），按 K6 确认。键盘重启，进入 180 秒配网窗口。
2. 手机打开涂鸦 App，按提示添加设备，选择新的 Wi-Fi（只支持 2.4 GHz）并输入密码，等待配网完成。
3. 配网成功后键盘恢复使用，新网络会进入已保存列表。

键盘上也有说明：设置里选中「更换 Wi-Fi」，或在「已保存的 Wi-Fi」页，按 **K4** 打开「更换 Wi-Fi 环境」页，K1、K4 或单击旋钮返回。

**为什么没有蓝牙换 Wi-Fi？** Companion 的蓝牙连接不能写 Wi-Fi：写 Wi-Fi 和 Tuya UUID/AuthKey 必须经 USB，因为蓝牙无法证明你就在键盘旁边。涂鸦 App 的蓝牙「更换网络」目前也不支持已绑定的键盘。

### 6.3 配网窗口

配网窗口是键盘上开 180 秒的临时通道，允许写入 Wi-Fi 和 Tuya UUID/AuthKey。窗口开着时，蓝牙留给涂鸦 App 配网。在键盘上打开：设置 →「配网模式」或「更换 Wi-Fi」→ K6 确认。也可以在 Companion「连接」页「配网窗口」点「在键盘上打开」，再到键盘上按 K6 确认。屏幕上方显示「配网窗口 m:ss（USB）」倒计时。K1 取消，10 秒不操作自动取消。

## 7. 升级

目前不提供预编译的固件和 Companion，也没有签名的 `.akota` 升级包，所以升级就是自己重新构建。

### 7.1 固件

1. 拉取最新代码，按[固件说明](../firmware/app/README.md)的 Build 一节用 release 配置重新构建。
2. 关掉 Companion（它占着串口），按 Flash 一节用 `tos.py flash` 或 tyutool 把新的 `app_QIO_<版本>.bin` 烧录到键盘。
3. 重启后，顶栏的版本号变成新版本。

Companion「高级设置」页里的「固件升级（USB）」是以后发布签名升级包用的，现在用不上。有了正式发布的签名密钥后，会恢复经 Companion 用 `.akota` 本地升级的方式，到时本节会更新。

重新烧录后，请到「设置 → 设备信息」确认 Tuya PID、UUID、AuthKey 是否还是「已设置」。如果变成「未设置」，按 2.5 重新写入。

### 7.2 Companion

Companion 没有自动更新。拉取最新代码，按仓库根目录 README 的 Build 一节重新构建并运行。

升级后，建议固件和 Companion 都保持最新。固件较旧时，Companion 里个别设置会显示「等待键盘同步」或不可用。

## 8. 常见问题

每条按「现象 → 原因 → 怎么办」写。

### 键盘上按单击反应慢半拍

- **原因**：键盘要等 0.25 秒才能确定你是单击还是双击，但只有**设了双击的键**才等。默认只有 K6 设了双击（切换模型），所以 K6 单击是松手后约 0.25 秒才生效。K1–K4 默认没有双击，单击松手就响应。
- **怎么办**：按 K6 后稍等一下再看反应。菜单里的按键、K5 语音键不受影响：菜单里按下松开就生效，K5 按下立刻开始录音。

### 键盘按了，电脑上没反应

- **原因**：①「板子按键驱动 Kiro Crew」是「关」；② Kiro Crew 窗口不在前台，键盘提示「Crew 窗口不在前台」；③ Companion 没连上键盘。
- **怎么办**：Companion「输入」页确认总开关是「开」；把 Kiro Crew 窗口打开；看 Companion 右上角是不是「在线」。

### 绑定会话时提示「无法获取会话列表」

- **原因**：Companion 没能从 Kiro Crew 取到会话列表。常见情况是 Kiro Crew 没运行、刚重启、或 Companion 没连上它。同类提示还有「Crew 离线」。「Companion 未响应」则是键盘没连上 Companion。
- **怎么办**：
  1. 确认 Kiro Crew 在运行，并且和 Companion 是同一个 Windows 用户。
  2. 看 Companion「控制」页「实时连接」是不是「已连接」。不是的话，先点「刷新」；如果显示「Crew 身份校验失败」，看下一条。
  3. 确认 Companion 和键盘是连着的（右上角「在线」）。
  4. 回键盘重新进「设置 → 绑定会话」。

### Companion 显示「Crew 身份校验失败」

- **原因**：Companion 连接 Kiro Crew 前，会先检查监听本机端口（默认 5476）的程序确实是你自己用户下运行的 Kiro Crew。检查没通过就不会连接，也不会发送任何密钥。可能是 Kiro Crew 没在运行，也可能是别的程序占了这个端口，或 Kiro Crew 和 Companion 是不同的 Windows 用户。键盘也会提示一次「Crew 身份校验失败」。
- **怎么办**：打开 Kiro Crew 桌面版并等它启动完成；用同一个 Windows 用户运行 Kiro Crew 和 Companion（不要一个以管理员身份运行、另一个不是）；关掉占用 5476 端口的其他程序；然后重启 Companion。Companion 会每隔几秒自动重试。

### 蓝牙连不上，或状态栏提示「蓝牙已连接，等待认证」

- **原因**：蓝牙要用配对密钥加密。没有配对（或配对密钥对不上，例如键盘又和别的电脑配过对）时，键盘不理会这台电脑的蓝牙连接。「等待认证」说明有设备连上了键盘的蓝牙，但还没通过认证，可能是手机上的涂鸦 App，也可能是还没配对的电脑。另外，「配网模式」的 180 秒窗口开着时，蓝牙留给涂鸦 App，Companion 连不上。键盘有没有绑定涂鸦不影响蓝牙。
- **怎么办**：
  1. 电脑打开蓝牙，Companion「传输方式」选「自动」或「BLE」，点「扫描」选中键盘（名字形如 `Ki-board-XXXXXX`，后 6 位是键盘 Wi-Fi MAC 地址的后 6 位，可在键盘「设置 → 设备信息」里核对）。找不到时，确认键盘没有处在「配网模式」窗口里（等 180 秒，或配网完成后自动关闭）。
  2. 没配对过，或被别的电脑替换过：在键盘上「设置 → 蓝牙配对」单击打开窗口，再在 Companion 点「蓝牙配对」，核对比对码后按 K6（步骤见 2.3）。窗口 120 秒，失败 3 次会关闭，要重新打开。
  3. 比对码不一致、没有弹出对话框或提示「蓝牙配对失败」：在键盘上重新打开窗口再试。键盘提示「蓝牙未启用，无法配对」说明蓝牙没开，常见原因是 Companion 当时选了 USB。
  4. 还不行，在键盘「设置 → 设备信息」里连按两次 K1 清除蓝牙配对，再配对一次。

### Companion 找不到键盘（USB）

- **原因**：USB 线只能充电；电脑缺串口驱动；有别的程序占着串口（例如烧录工具）。
- **怎么办**：换一根能传数据的线；在设备管理器里看有没有新的串口设备，没有就安装 CH343 系列串口驱动；关掉其他占用串口的程序后，在 Companion 点「连接」。

### 换了 Wi-Fi 环境，键盘连不上网

- **原因**：新环境是键盘没连过的网络（或已被新网络覆盖出列表），而键盘不能通过蓝牙收到新的 Wi-Fi。
- **怎么办**：回到连过的地方会自动重连；到没连过的新环境，按 6.2 的做法 ② 或 ③。有 USB 线就用「更换 Wi-Fi」，绑定不会丢。没有 USB 线，才用「解绑设备」加涂鸦 App，原绑定会丢失。再检查路由器是 2.4 GHz，没有开 AP 隔离或需要网页登录的认证。

### 配网失败，或提示配网只能经 USB

- **原因**：
  - 写入 Wi-Fi 和 Tuya UUID/AuthKey 的命令只收 USB，并且必须在 180 秒窗口里。键盘提示「请先在设置中打开配网模式」就是窗口没开或已过期。
  - 键盘上已有 Tuya UUID/AuthKey 时，Companion 要写新的会被拒绝，提示「已有 Tuya UUID/AuthKey：请先允许覆盖」。
  - 手机搜不到键盘：窗口过期，或没有给涂鸦 App 开蓝牙和附近设备权限。
- **怎么办**：用 USB 连接，在键盘上重新打开配网窗口（K6 确认）再在窗口内操作。需要覆盖 Tuya UUID/AuthKey 时，在配网窗口开着时进「设置 → 设备信息」按 K6 允许一次。手机配网时，确认键盘屏幕上写着「配网模式：请用涂鸦 App」，并且 Wi-Fi 是 2.4 GHz。

### 键盘提示「警告：Wi-Fi 连接失败」或「警告：Wi-Fi 已断开」

- **原因**：密码错、路由器不在范围内，或网络本身断了。开机或断线后自动重连时，状态栏先显示「连接 Wi-Fi…」，30 秒还没连上才变成「警告：Wi-Fi 已断开」，这期间键盘一直在重试，不是卡住。
- **怎么办**：先等一会儿。仍然不行，到「设置 → 已保存的 Wi-Fi」看当前有没有「当前」标记。需要的话用 USB 重新写入正确的密码（同名网络会更新密码）。

### 语音没反应，或识别不准

- **原因与办法**：

  | 屏幕提示 | 原因 | 怎么办 |
  |---|---|---|
  | 「警告：没有听到语音」或「没听清」 | 按得太短，或离麦克风太远 | 按住 K5 不放，说完再松开，靠近一点 |
  | 「涂鸦 ASR 不可用，改用 PC ASR」 | 键盘没联网，云端识别不可用 | 检查 Wi-Fi，或直接用电脑识别 |
  | 「电脑识别:没有 Key」 | 选了豆包或阿里云，但没填 API Key | 在「输入」页对应引擎里填 Key 并保存 |
  | 「电脑识别:Key 无效」 | Key 填错，或没开通服务 | 重新生成 Key，确认服务已开通 |
  | 「电脑识别:网络错误」 | 电脑没连上识别服务 | 检查网络；或勾选自动改用本地识别 |
  | 「本地模型未下载」 | 选了本地离线，或在线失败后要改用本地，但模型没下载 | 在「输入」页点「下载本地模型」（约 245 MB），等显示「已就绪」 |
  | 「电脑麦克风错误」 | 电脑的麦克风被占用或没打开 | 检查 Windows 麦克风权限和默认录音设备 |
  | 「警告：语音识别超时」 | 15 秒内没有结果 | 重新说一次，检查网络 |
  | 「语音需要连接 Companion 或完成配网」 | 键盘云端识别用不了，Companion 又没连上 | 连上 Companion（USB 或已配对的蓝牙），或按 2.5、2.6 写好 Tuya UUID/AuthKey 并配网 |
  | 「语音需要打开键盘控制电脑」 | Companion 开着，但「键盘控制电脑」关了 | 在 Companion「输入」页把「板子按键驱动 Kiro Crew」打开 |
  | 「云不可用：本次按语音输入」 | 语音模式是「对话」，但涂鸦云暂时用不了 | 这一次按「语音输入」处理，文字进输入栏。云恢复后自动回到对话 |
  | 「输入栏已满，多的字没有记下」 | 输入栏放满了（约 126 个汉字或 380 个英文字符） | 先按 K6 发送，或长按 K4 清空 |
  | 「未发送：K6 重发」或「未连接 Companion，文字已保留」 | Kiro Crew 没开、没登录、这个键没有绑定对话，或键盘没连上 Companion | 文字还在输入栏，处理好后再按 K6 |
  | 「对话模式需要涂鸦云」 | 语音模式是「对话」，但键盘没联网或没绑定 | 联网并绑定，或切回「语音输入」 |

- **识别不准**：靠近说话，语速平稳。在「输入」页「热词」里加入常用的专有名词（豆包和阿里云 Fun-ASR 支持；本地离线不支持）。

### 屏幕字太小，或太大

- **怎么办**：「设置 → 字号」，在 12、14、16 px 里选，默认 12。也可以在 Companion「设备设置」页「键盘设置」里改「屏幕字号」。

### 电量显示不对

- **原因**：电量是按电压估算的，插拔充电线时会重新校准，数字会跳一下。读不到电量时，顶栏不显示电池图标。
- **怎么办**：平时参考即可。要判断是否能升级固件：接上 USB 供电，或电量不低于 30%。

### 灯不亮了

- **原因**：灯光电源设成了「自动」，空闲超过设定时间后熄灯；或设成了「关」。
- **怎么办**：按任意键、转一下旋钮，灯会重新亮起。想一直亮，在设置里把「灯光电源」设为「常开」。

### 菜单里的键按了没反应

- **原因**：菜单刚出现的 0.3 秒内按键无效；权限审批菜单里 K6 和旋钮按下不起作用，只能按选项对应的键；需要二次确认的选项第一次按只会让灯快闪。
- **怎么办**：等灯亮稳再按；审批请按选项对应的键；快闪时 3 秒内再按一次同一个键。

### 键盘卡住、界面异常，或想重新开始

- **怎么办**：任何界面下，**同时按住 K1 和 K6 约 5 秒**。按住期间 K1、K6 黄色常亮，到时间后 K6 黄色快闪、K1 红色，屏幕显示「解绑设备，重新配网？」。松开两键，再按一次 K6 确认，或按 K1 取消，10 秒不操作自动取消。屏幕坏了也能做：等 K6 开始黄色快闪，松开两键，再按一次 K6。
- **按键会暂时失灵**：两键一起按下后，它们的单击、双击、长按、菜单选项和对话框确认都不再生效，直到两键都松开。两键先后按下都可以。先按下的 K1 只会取消或返回，对话框只在松开 K6 时确认，所以不会误触发。
- **注意**：确认后会清除涂鸦绑定和当前 Wi-Fi，重启进入配网窗口。Tuya UUID/AuthKey 和已保存的 Wi-Fi 列表保留，需要在涂鸦 App 里重新绑定。键盘还没绑定涂鸦时，这个组合键的效果和「配网模式」一样；没写 Tuya UUID/AuthKey 时只提示「未写 Tuya UUID/AuthKey，只能用 USB 配置」。硬件测试页里这个组合键不起作用。
- **想彻底回到新板子的状态**（包括清掉 Tuya PID、UUID/AuthKey 和所有设置）：用「设置 → 重置系统」，见第 4 节。
