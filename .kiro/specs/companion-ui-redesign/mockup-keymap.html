v0.3 Keymap 配置面板 — 3 个交互方案

同一套 Kiro-Crew 令牌（kc-dark）。配置内容相同：每键角色 + K1-K3 的 chat#/instance# + 手势模式（由角色推断，只读）。差别在布局与交互模型。选一个方向。

方案 A — 紧凑表格

一行一个键，列=角色/手势/绑定。信息密度最高，一屏看全 7 键，像配置表。适合"一次调完所有键"的高级用户。

K2单/双击chat / inst
K3单/双击chat / inst

K5边沿按住说话
K6边沿单=确认
EC11边沿旋转/按下=本地

方案 B — 每键卡片

每个键一张卡，角色下拉 + "解析后快捷键"一行白话（如 单击→对话1(Alt+1)）。可读性最好，逐键理解在做什么；占空间更多。

方案 C — 键盘平面图

按物理布局画 K1-K6 + EC11，点一个键在下方检查器里配置，并顺带画出 LED 灯位+图例。最直观"哪个键在哪"；适合非技术用户，一次配一个键。
