# 引脚映射与硬件连接清单（Task 2，v0.2 冻结基线）

> 版本：**v0.2**（旧硬件 PCB 丝印 **v1.2.0**）。本文件集是 v0.2 定格快照的带后缀副本，
> 仅为与 v0.3 命名对齐而加 `-v0.2` 后缀；当前演进版见无后缀文件及 `*-v0.3`。版本规范见 `docs/versioning.md`。

路线：**T5AI-Core 成品开发板** 插到**自制扩展底板 PCB**（44P 排针）。
扩展底板承载 5键 + 5向摇杆 + LCD FPC 座 + Type-C(CH340C,可烧录+通信) + 锂电池并联座(带总开关)
+ 3×WS2812(经电平转换) + 保护/去耦；充电管理(ETA6003)/音频/MIC 由开发板负担。

## 核心结论

- **输入分配（落在排针 J2 实际引出脚）**：KEY1-5 = P24/P25/P26/P27/P23；
  NAV 上/下/左/右/中 = P32/P20/P21/P22/P30。全内部上拉、低有效。
- **LCD**：沿用官方 ST7789 接线（P14/16/15/17/6/5/7），固件仅改分辨率 240→320；
  18P FPC 逐脚定义已确认（4线SPI+电阻触摸，见 pinmap-v0.2.md §3）。
- **44P 排针** = 2× 1×22 单排（J1+J2），逐脚映射见 pinmap-v0.2.md §8。
- **采购**：T5AI-Core 开发板 ×1、18P 0.5mm FPC 座、2 条 1×22 母排（详见 bom-v0.2.md）。
- **三个原待确认项已全部由资料核实**（44P 位号 / 18P FPC / 摇杆脚序）。
  剩余实机项：SPI 阻尼/背光限流阻值、方向↔上下左右标定。
