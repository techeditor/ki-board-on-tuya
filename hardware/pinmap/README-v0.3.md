## 硬件摘要

T5AI-Core 通过44P排针连接无源扩展板。扩展板只承载：

- 6个机械按键K1–K6，Kailh C2803348热插拔轴座；
- 1个EC11编码器（A/B正交输出+按键）；
- 7颗C2890364可编程RGB LED，LED1–LED6用于六键，LED7用于EC11；
- T280C7-C12-26 2.8英寸LCD，ST7789P3，12P/0.5mm下接FPC；
- 必要的电平转换、背光开关、滤波、去耦和储能电容。

扩展板不含USB、USB-UART、电池座、充电管理和电源开关；这些功能全部由T5AI-Core承担。
