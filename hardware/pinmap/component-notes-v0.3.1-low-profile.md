## 1. WS2812B-MINI-V3J（直脚，3535）

### 电气（规格书）

| 参数 | 值 | 和旧灯 C2890364 比 |
|---|---|---|
| 脚序 | **1=VDD、2=DOUT、3=GND、4=DIN** | 旧灯：1=GND、2=DI、3=VDD、4=DO，**不能混用封装** |
| VDD | **+3.7 ~ +5.3V**（绝对最大值） | 旧灯 4.5–5.5V；5V 轨的上限余量变小 |
| VIH / VIL | ≥0.65·VDD / ≤0.7V | 5V 时 VIH=3.25V → 必须经 U2 转到 5V |
| 数据速率 | 800kbps，GRB，高位先发 | 相同 |
| T0H / T1H | 220–380ns / 580ns–1µs | — |
| T0L / T1L | 580ns–1µs | — |
| **RESET** | **≥280µs** 低电平 | 旧灯 ≥80µs → **固件要核对** |
| 发光（12mA/色） | R 300–400、G 800–1000、B 200–300 mcd | — |
| 静态电流 | <0.6mA | — |
| 去耦 | 规格书建议 VDD–GND 加 100nF | 本板每颗 1 个（C3–C9） |
| 工作温度 | −40 ~ +65℃ | — |
| 湿敏等级 | **MSL 5a**（拆袋后 24h 内回流） | SMT 前 70–75℃ 烘 ≥24h；散料 120℃ / 4h |
| 回流 | 峰值 245℃，液相 217℃ 以上 45–90s | — |

### 封装与安装

- 4 个焊盘 0.90 × 1.60mm，位于 (±0.90, ±2.80)mm；Pin1 在 (−0.90, +2.80)。
- 封装内含 **Multi-Layer 圆角方形挖槽 3.81 × 3.81mm**（本体 3.5 × 3.5mm）：灯珠从顶层反贴进挖槽，光线照向底层（轴体 / 键帽面）。
- 7 颗都在顶层，旋转 90°；U4–U9 中心 = 对应键中心沿 Y 偏 5.0mm（顶层坐标，朝板下方）。
- 丝印有 Pin1 标记；手焊时注意直脚要贴平焊盘，本体不能顶到挖槽边。

### 固件要点

- 灯数 7、灯序 U4→U10（K1..K6、EC11），`AK_WS2812_COUNT = 7U`，与现有 `ak_board_io.h` 一致。
- 现在用 TuyaOpen `tdd_ws2812_driver_register`（SPI1，P4）。**要确认该驱动每帧之后的低电平 ≥280µs**；
  如果是按旧 WS2812 的 50 / 80µs 写的，需要补一段全 0 字节（SPI 时钟按驱动配置换算），或者两帧之间至少隔 300µs。
- 亮度上限 `AK_LEDS_MAX_LEVEL = 48`，电流远低于满白 ~250mA，可保留。

## 2. 矮轴轴体（K1–K6）

- 封装 `九紫矮轴-白雪轴-无焊盘`：**没有铜焊盘**，只有机械孔：
  - 中心孔 Ø5.0mm；两侧定位孔 Ø1.7mm，位于 (±5.0, 0)。
  - 丝印 Ø2.5mm 圆 × 2：(0, +6.0) 与 (−4.15, +3.35) —— 标的是轴的两个电气引脚。
  - 文档层：18.0 × 18.0mm 键帽框、约 13.9 × 13.9mm 本体框。
- 放在底层（正面），旋转 180°；键距 19.20mm。
- ⚠ EDA 元件属性仍是 `CPG151101D06 / C49234237`。`datasheets/CPG151101D06_茶轴开关.pdf` 写的是总行程 4.0 ± 0.4mm、
  导通行程 2.0 ± 0.6mm，是 **MX 全高轴** 的参数，**与矮轴封装不符**。请确认实际用的矮轴型号并改正属性。

## 3. 热插拔座（KEY1–KEY6）

- 封装 `CONN-SMD_MXT02`：
  - 2 个 SMD 焊盘 2.5 × 2.5mm：Pin1 (−5.55, +1.27)、Pin2 (+5.55, −1.27)。
  - 2 个 Ø3.0mm 孔：(−1.78, +1.27)、(+1.87, −1.37)。
- 放在顶层（背面），旋转 180°；Pin1 = KEYn，Pin2 = GND。
- ⚠ 两个座孔的间距（X 3.65mm、Y 2.64mm）与轴体封装引脚标记的间距（X 4.15mm、Y 2.65mm）**X 方向差 0.5mm**
  （放到板上后两个孔分别偏 +0.24 / −0.26mm）。孔径 3.0mm 比引脚标记 2.5mm 大，可能插得进去，但座子内部弹片
  对的是自己的孔位，**建议投板前用实物试插或对照规格书确认**。
- ⚠ 属性 `CPG151101S11` 据我所知是 Kailh **MX** 热插拔座的料号（库内描述“键盘轴连接器 停产”），没有 LCSC 编号，需换成实际矮轴座。

## 4. EC1106S（U3）

- 与 v0.3 相同：1=A、2=C（GND）、3=B、4=E（GND）、5=D（SW）、6/7=EP（GND）。
- 放在底层（正面），中心 (37.50, 88.00)mm；文档层旋钮圆 Ø25mm。
- U10（EC11 状态灯）在 (29.34, 92.33)mm，距 EC11 中心约 9.2mm，**在旋钮投影内**：不用透光 / 导光旋钮的话，灯光会被挡住。
