## 1. CH340C — USB 转 UART 桥

**用途**：扩展板 Type-C 的 USB↔串口桥，接 T5 UART0(P10/P11)，负责烧录 + 通信。

**关键参数**（沁恒公开规格）：
- 供电：VCC 支持 **5V 或 3.3V**；内置 3.3V LDO
- 波特率：50bps ~ 2Mbps（460800 烧录无压力）
- 免晶振（内置时钟），比 CH340G 少一个外部晶体

**接法要点**：
- **VCC=3.3V 供电时**：**V3 脚必须与 VCC 短接**（都接 3.3V）。⚠️ 本项目用此接法（VBUS→LDO→3.3V），故 V3 接 VCC，**不是接 100nF**。
- **VCC=5V 供电时**：V3 脚接 0.1µF 到地（内部 LDO 输出）。本项目**不用**此接法。
- VCC 去耦：100nF + 1µF 就近。
- USB D+/D-：接 Type-C 的 D+/D-；线上串 ESD（并联对地器件）。
  ⚠️ **UD+/UD- 不要额外串接电阻**（沁恒手册明确：USB 收发器按 USB2.0 全内置设计）。
- **IO 电平 = VCC 电平**：VCC=3.3V → TXD/RXD/DTR/RTS 都是 3.3V，直接接 T5 安全（这是本项目选 3.3V 供电的核心原因）。

**审核 checklist**：
- [ ] V3 与 VCC(3.3V) 短接？（最易错点）
- [ ] VCC 由 LDO 的 3.3V 供，不接系统 5V/3V3？
- [ ] TXD → T5 RX(P10) 串 2kΩ 隔离电阻（与 CH342F 共用总线）？

## 2. SN74LV1T34 — 单门电平转换（3.3V → 5V）

**用途**：把 T5 的 3.3V GPIO(P13) 抬到 5V，驱动 WS2812 的 DIN。

**关键参数**（datasheet 实读）：
- **单 buffer 门，有方向**（A 输入 → Y 输出，**单向**，不能反接）
- 工作电压 1.65~5.5V；**输出电平由 VCC 决定**（"Logic output is referenced to VCC"）
- 3.3V→5.0V 上转换：**VCC 接 5V**，输入接 3.3V 信号即可
- 输入 reduced threshold，**输入脚 5V 耐受**
- 带宽 **50MHz @3.3V VCC**（WS2812 800kHz 绰绰有余）
- 驱动能力 8mA@5V

**接法要点**：
- **VCC 接 5V**（不是 3.3V！VCC 决定输出高电平）
- 输入 A ← T5 P13（3.3V）；输出 Y → WS2812 DIN（5V）
- VCC 去耦 100nF
- ⚠️ **方向别接反**：这是 buffer 不是双向 translator，A→Y 单向

**审核 checklist**：
- [ ] VCC = 5V（决定输出 5V 电平）？
- [ ] A=输入(接P13)、Y=输出(接LED)，方向正确？
- [ ] VCC 去耦 100nF 就近？

## 3. S8050 — NPN 三极管（自动复位开关）

**用途**：CH340C 的 DTR/RTS → S8050 → 拉 T5_RST，实现自动进下载/复位。

**关键参数**（通用 NPN，SOT-23）：
- 类型：NPN；Vceo ≈ 25V（Y档）/40V（更高档）；**Ic max 500mA**；hFE ~ 120-400
- 用于小信号开关绰绰有余（复位只拉 mA 级）

**接法要点（照抄开发板 SCH，Q2 方案）**：
- **基极 B**：RTS0 直连 + DTR0 经 4.7kΩ 汇入（组合逻辑）
- **集电极 C**：经 100Ω 到 T5_RST
- **发射极 E**：接 GND
- 复位逻辑：RTS/DTR 组合把基极拉高 → Q2 导通 → 集电极拉低 → T5_RST 被拉低复位
- T5_RST 上拉 10kΩ→3V3 + 0.1µF：**开发板已有**（J2.2 处），扩展板可不重复

**审核 checklist**：
- [ ] B/C/E 三脚朝向对（SOT-23 引脚定义）？
- [ ] R_DTR=4.7k、R_RST=100Ω？
- [ ] E 接地、C 经 100Ω 到 T5_RST(J2.2)？

## 4. WS2812 (XL-3528RGBW) — 单线 RGB LED

**用途**：3 颗菊花链，Agent 状态指示灯。

**关键参数**（datasheet 实读）：
- **供电 VDD 3.5-5.5V**（≥4.5V 才 100% 保证正常，故用 **5V**）
- **逻辑输入 VDI = −0.5 ~ VDD+0.5V** ⚠️ → 5V 供电时高电平阈值约 0.7×VDD≈3.5V，**3.3V 直驱不可靠 → 必须电平转换**（这就是要 SN74LV1T34 的原因）
- 数据率 800Kbps 单线；256 级/通道灰度；12mA/通道恒流
- 输出端口耐压 12V；ESD 2000V HBM
- **回流焊 260°C / 6s max；MSL 5 级**（湿敏，需烘烤/注意存储）
- 工作温度 -40~+85°C
- 单颗全亮(RGB全开) ≈ 3×12mA ≈ **36-60mA**，3 颗 ≈ 110-180mA

**接法要点**：
- 5V 供电（本项目取自排针 J1 的 VCC_5V，来自开发板 LN2220 升压域）
- DIN 串 **100-330Ω** 抑制振铃/保护首颗
- **每颗就近 100nF 去耦**（必须，避免数据抖动/闪烁）
- 菊花链：LED1.DOUT→LED2.DIN→LED3.DIN
- 数据经 SN74LV1T34 抬到 5V 再进 DIN1

**审核 checklist / 坑点**：
- [ ] DIN 前有电平转换（3.3→5V）？直驱是最常见失败原因
- [ ] 每颗 100nF 去耦到位？
- [ ] DIN 串阻 100-330Ω？
- [ ] ⚠️ **电源风险**：VCC_5V 与开发板音频功放**共用升压域**（LN2220，电感 4.7µH/2.85A）。3 颗全白 ~180mA，与功放同时大电流时可能拉低 5V。**建议固件限制亮度（30-50%）** 把峰值压到 <100mA。
- [ ] MSL5 湿敏：贴片前注意烘烤/开封时限

## 5. HE9073A33M5R — 3.3V LDO（专供 CH340C）

**用途**：把 Type-C VBUS(5V) 降到 3.3V，独立给 CH340C 供电（不依赖电池、不进系统）。

**关键参数**（datasheet 实读）：
- 输入电压 **up to 7V**（5V VBUS OK）
- 输出 3.3V（A33 档），精度 **±1%**
- **输出电流 ≥500mA**（CH340C 只需 ~30mA，余量巨大）
- 压差 100mV@100mA（5V 输入无压力）
- 静态电流 0.3µA（Typ）
- **兼容低 ESR 陶瓷电容**（省成本、稳定）
- 内置 **限流 / 短路保护 / 过温保护**、Enable 脚
- PSRR 70dB@1kHz
- SOT-23-5 封装

**接法要点**：
- IN ← Type-C VBUS(5V)；OUT → CH340C VCC(3.3V)
- IN/OUT 各接陶瓷电容（典型 1µF；按 datasheet 应用电路）
- EN 脚：常使能可上拉到 IN（或按 datasheet 接法）
- **不接系统 3V3/5V**——这是独立供电轨，只喂 CH340C

**审核 checklist**：
- [ ] IN=VBUS 5V、OUT=CH340C VCC，方向对？
- [ ] IN/OUT 陶瓷电容在位（1µF 级）？
- [ ] EN 脚正确使能？
- [ ] 输出未与系统 3V3 短接（保持独立轨）？

## 6. SK12D07VG5 — 迷你拨动开关（电池总开关）

**用途**：串在扩展板电池 BAT+ 路径，做电池总开关（关机切电池，Type-C 不受影响）。

**关键参数**（首韩官方规格书，已核实）：
- 类型 **SPDT（单刀双掷）**，卧式拨动
- **额定 DC 50V / 0.3A**（官方规格书明确值）
- 接触电阻 ≤30mΩ；绝缘电阻 ≥250MΩ；耐压 AC250V/1min
- 操作力 130~330gf；行程 2mm±0.2；温度 -25~+70°C

**接法要点**：
- 只用 2 个脚（公共 + 一个常通位）做通断，串在 BAT+ 路径
- ⚠️ **电流校核（重要）**：官方额定 **0.3A**。整机电池峰值电流需 < 0.3A：
  - 主要负载 T5(峰值~150mA) + LCD(~40mA) + WS2812(3颗全白~180mA) 叠加**可能超 0.3A**
  - **缓解**：固件限制 WS2812 亮度（状态灯 30-50%），把 LED 峰值压到 <60mA → 整机大概率 <0.3A
  - 若仍担心，改用额定更高的开关（如 SK-12E12 或 0.5A/1A 款）
- 开关只在电池供电路径，Type-C 供电时不流经它

**审核 checklist**：
- [ ] 串在 BAT+（非 GND、非系统电源）？
- [ ] 开关额定电流 ≥ 整机电池峰值电流？（⚠️ 需校核，0.3A 可能偏紧）
- [ ] 丝印标注 ON/OFF 方向？

## 附：跨器件的电源与信号总览（审核用）

```
Type-C VBUS(5V) ──→ HE9073A33 LDO ──→ 3.3V ──→ CH340C VCC (独立,不进系统)
                                                  CH340C TXD ─2kΩ─→ T5 P10(RX)
                                                  CH340C RXD ←──── T5 P11(TX)
                                                  CH340C RTS ──┬─→ S8050 基极
                                                  CH340C DTR ─4.7k┘   S8050 C ─100Ω─→ T5_RST(J2.2)

电池 ──→ SK12D07VG5(总开关) ──→ BAT+ (并入开发板同 BAT 网, ETA6003 充电)

排针 J1 VCC_5V(开发板LN2220升压) ──→ WS2812 VDD(×3) + SN74LV1T34 VCC-B
T5 P13(3.3V) ──→ SN74LV1T34(A→Y,VCC=5V) ──→ 5V DIN ─100~330Ω─→ WS2812链
```

**三个最易错/高风险点**（审核重点）：
1. **CH340C V3 脚**：3.3V 供电时必须与 VCC 短接（非接电容）
2. **WS2812 电平转换**：3.3V 不能直驱 5V 供电的 DIN，必须过 SN74LV1T34
3. **WS2812 电源争用 + 开关额定**：LED 与音频共用升压 5V（固件限亮度）；电池开关 SK12D07VG5 **额定 0.3A（官方确认）**，整机峰值可能触及，靠限亮度压低或换更高额定开关
