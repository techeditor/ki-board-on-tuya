## 总原则：lite = 无源扩展板

v0.3 把扩展板简化为**纯无源功能板**：只保留 **按键 + EC11 + WS2812 + LCD** 及其**必要辅助电路**，
以及 **44P 排母**（取 3.3V/5V/GND、接 T5 GPIO）。**所有 USB / 电源 / 充电 / 电池电路删除**，交回开发板。

## B. 按键 K1–K6（热插拔轴座）

### 变更

- 数量5 → **6（K1–K6）**，不设置K7。
- 安装：直焊CPG151101 → **热插拔轴座Kailh C2803348**（MX兼容，PCB只放轴座+2焊盘）。

### 电路（每键，6路相同）

```
T5 GPIO(内部上拉) ── 轴座脚1
                     轴座脚2 ── GND
```

- **主方案**：依赖 **T5 内部上拉 + 固件去抖**，每键只需轴座 2 脚（一脚 GPIO、一脚 GND），**无外部器件**。
- **辅助电路（可选，推荐保留焊盘）**：每键 GPIO 对 GND 并 **100nF（C_KEYn）** 做硬件去抖 / 抗 ESD。
  - 布局上给每键预留一个 0402 电容焊盘；不需要时贴 0Ω 或空贴。
  - 若外壳金属化 / 走线长，可再串 **100Ω（R_KEYn）** 限流 + 对地 ESD（预留焊盘，默认空贴）。

### 引脚

K1=P24, K2=P25, K3=P26, K4=P27, K5=P23, K6=P32；**P30释放为空闲/预留**。

### 验收

- K1–K6每个轴座：一脚连接对应GPIO，另一脚连接GND。
- 固件按低有效扫描6键；不存在KEY7网络或K7焊盘。

## C. EC11 旋转编码器（替代 5 向摇杆）——含辅助电路

### 变更

- 删除 WS-1002 摇杆（v0.2 EDA 位号 **SW2** + 扩展焊盘 **U4**）。
- 新增 **EC11 编码器**（贴片，C9900001788；参考规格书 `datasheets/EC11I-152 Datasheet.pdf` **已放入并核实**）。
- EC11 提供：**A/B 两相正交** + **旋钮按下 SW**。占 **3 GPIO**：A=P20、B=P21、SW=P22；C/按键公共端接 GND。

### 是否需要辅助电路：**需要（强烈建议）**

机械式 EC11 触点在旋转切换时**抖动明显**，若只靠内部上拉裸接，A/B 相易产生**多重误计数 / 方向误判**。
业界标准做法是 A/B 相各加 **RC 低通硬件去抖**；旋钮按键可较宽松（软件去抖即可，但也建议留 RC 焊盘）。

### 推荐辅助电路（A、B 两相各一套；SW 一套简化）

### 引脚定义（EC11I-152 datasheet 已核实）

型号 **EC11I-152**（深圳百斯特，11mm 增量式旋转编码器，额定 DC 5V）。引脚（见规格书成品图）：

| 端子 | 功能 | 接法 |
|---|---|---|
| **A** | 编码相 A | 上拉 + RC → GPIO（P20） |
| **C** | 编码公共端（A/B 中间脚） | **接 GND** |
| **B** | 编码相 B | 上拉 + RC → GPIO（P21） |
| **D** | 按键 SW 一端 | → GPIO（P22） |
| **E** | 按键 SW 另一端 | **接 GND** |

- 编码侧一排 3 脚顺序 **A–C–B**（C 居中为公共）；按键侧 2 脚 **D/E**。
- PCB 焊盘：编码侧 3 脚（间距 2mm，孔 φ1.0）+ 按键侧 2 脚（孔 φ1.2）+ 两侧定位脚，
  按 datasheet「P.C.B. MOUNTING DETAIL」布局（贴片/插脚混合，外形 15×16mm 区域）。

### 辅助电路（按 datasheet 图 1 官方推荐 — 强制）

规格书第 4-4 条明确要求「设计时考虑杂讯，**建议使用 R/C 滤波电路（图 1）**」，第 4-3 条建议
「以 A 相为参考基准」。官方图 1 的 A/B 两相各为：**上拉 10kΩ + 串联 10kΩ + 对地 0.01µF**。

**编码相 A / B（各一套，共 2 套）——按官方图 1：**
```
3V3 ──[ R_ECA_PU 10kΩ ]── EC11.A ──[ R_ECA_S 10kΩ ]──┬── EC11_A(P20) 到 T5 GPIO
                                                       └──[ C_ECA 0.01µF ]── GND
（B 相同：R_ECB_PU 10kΩ 上拉 + R_ECB_S 10kΩ 串联 + C_ECB 0.01µF 到 GND，接 P21）
```
- **上拉 10kΩ**：datasheet 图 1 上拉到 DC 5V；本项目逻辑 3.3V，**上拉改接 3V3**（T5 GPIO 无 5V 容忍风险）。
- **串联 10kΩ + 对地 0.01µF**：RC 去抖（时间常数 ~100µs），滤除触点弹跳毛刺。**阻容值即采用 datasheet 图 1 标称**。
- 每相共 **2 电阻（10k 上拉 + 10k 串）+ 1 电容（0.01µF）**；A/B 两相合计 **4 电阻 + 2 电容**。

**旋钮按下 SW（D–E，一套）：**
```
3V3 ──[ R_ECSW 10kΩ(可选) ]── EC11.D ──┬── EC11_SW(P22) 到 T5 GPIO
                                        └──[ C_ECSW 0.1µF ]── GND
EC11.E ── GND
```
- 按键 datasheet 未强制 RC；沿用惯例：可仅内部上拉 + 软件去抖，**推荐预留 0.1µF 对地 + 可选 10k 外部上拉**焊盘。

**公共端：** 编码公共 **C → GND**；按键公共 **E → GND**。

### 布局

- EC11 放**第 3 行**（旋钮 + 按下）；旋钮轴心与外壳开孔对齐。
- RC 器件就近放在 EC11 引脚旁，缩短 A/B 走线；A 相为固件参考基准。

### 额定与注意（datasheet）

- 额定 **DC 5V**；各相导线 max 5mA、公共端 max 10mA（阻性负载）。本项目 3.3V + 10k 上拉，电流远低于额定。
- 使用温度 −30～+80℃；请勿沾水（会导致输出波形异常）。

### 验收

- 顺/逆旋转在 A/B 产生干净正交脉冲（示波器无明显毛刺）；固件判向/计步正确、无跳数。
- 旋钮按下 SW 对 GND 导通；无连击误触。

## D. WS2812 ×7（每键下方 1 颗）——C2890364 新器件

### 器件与封装变更

- v0.2：**C3646929 / XL-0807RGBC-2812B**，2.0×1.8×0.8mm。
- v0.3：**C2890364 / XL-3528RGBW-WS2812B**，**3.5×2.8×1.85mm**，JLC 系统封装
  **`LED-SMD_4P-L3.5-W2.8-BR-1`**。
- 数量3 → **7颗**：LED1–LED6分别位于K1–K6下方，**LED7位于EC11下方/附近**作为旋钮状态灯。
- 参考：`datasheets/C2890364_RGB+LED(内置IC)_XL-3528RGBW-2812B_规格书_WJ1845755.PDF`。

> ⚠️ **不能只替换 PCB 封装**：新旧器件的引脚编号完全不同。必须使用 C2890364 对应的
> 原理图符号 + 封装，并重新核对每一颗的 DI/DO/VDD/GND 网络。

### 新器件脚序（顶视图，斜角位于右下）

| 引脚 | C2890364 功能 | 顶视图位置 |
|---|---|---|
| **1** | GND | 右下（斜角标记） |
| **2** | DI（数据输入） | 右上 |
| **3** | VDD | 左上 |
| **4** | DO（级联输出） | 左下 |

旧 C3646929 脚序为 `1=DO、2=GND、3=DI、4=VDD`；新 C2890364 为
`1=GND、2=DI、3=VDD、4=DO`，禁止沿用旧封装焊盘编号。

### 电路与级联

```
P4(3.3V) ── SN74LV1T34.A
SN74LV1T34.Y ──[ R3 100Ω ]── LED1.Pin2(DI)
LED1.Pin4(DO) → LED2.Pin2(DI) → … → LED7.Pin2(DI)
每颗 LEDn：Pin3(VDD)=VDD_5V；Pin1(GND)=GND；VDD-GND 就近并 100nF
```

- 数据协议不变：800kHz、24bit、**GRB 高位先发**；RESET 低电平必须 **≥80µs**。
- 新器件 `VIH(min)=0.5×VDD`，5V 供电时门限约 2.5V；3.3V 理论上可识别，但继续保留
  **SN74LV1T34** 可获得更好的温度/压降/噪声余量。

### 辅助电路

- **逐颗去耦（必需）**：每颗就近 **100nF**；LED1–LED7 共 7 个。规格书明确不建议省略。
- **链路入口串阻**：保留 **R3=100Ω**，位于 U2.Y 与 LED1.DI 之间；100Ω 位于规格书建议的
  20Ω–2kΩ 范围。若相邻灯珠走线较长，可为每段 DO→DI 预留 0–100Ω 串阻焊盘，默认直连。
- **入口储能（建议）**：灯链 VDD_5V 入口加 **47µF**（允许 10–47µF）+ 100nF。
- **电平转换去耦**：SN74LV1T34 的 5V VCC 就近 **100nF**。
- 5V/GND 主干建议 ≥0.8mm，去耦回路短且直接回地。

### 功耗预算（按 C2890364 规格书修正）

- RGB 每通道恒流典型 **12mA**，芯片静态电流典型 **0.5mA**。
- 单颗全白典型约 `3×12mA + 0.5mA = 36.5mA`。
- 7 颗全白典型约 **255.5mA @5V**；电源与布线按 **≥300mA** 留余量。
- 仍建议固件限制总体亮度，避免持续全白，减少发热和开发板电源负担。

### 装配注意

- MSL **5**：开封后建议在 ≤30℃、<40%RH 环境中 **24小时内**完成焊接；超时按规格书
  `60±5℃ / 24h` 烘烤。
- 推荐峰值回流温度 **240±5℃ / 6s**；最多两次回流，两次间隔控制在 8h 内。
- 丝印标出 **Pin1 斜角**和数据流方向 `DI → DO`，防止 3528 封装旋转 90°/180°。

### 验收

- 逐颗核对：Pin1=GND、Pin2=DI、Pin3=VDD_5V、Pin4=DO。
- 7 颗可独立寻址，链路顺序 LED1→…→LED7；GRB 色序正确。
- 第 7 颗不焊时，前 6 颗正常；末端 LED7.DO 可悬空或留测试点。
- 7 颗全白实测 5V 压降建议 <0.25V。

## E. LCD 12P（T280C7-C12-26 / ST7789P3）——已核实

### 变更与逐脚接法

- 18P（CL28CK230-18A，含 RTP）→ **12P（T280C7-C12-26，无触摸）**。
- FPC 座：**C2856799 / FPC-05F-12PH20 / 0.5mm 下接**。

| FPC Pin | 信号 | 接法 |
|---|---|---|
| 1 | GND | GND |
| 2 | RESX | LCD_RST / P6 |
| 3 | SDA | LCD_MOSI / P16，经 0–22Ω |
| 4 | SCL | LCD_SCK / P14，经 0–22Ω |
| 5 | CSX | LCD_CS / P15 |
| 6 | DCX | LCD_DC / P17 |
| 7 | TE | **NC/悬空**（LCD 输出） |
| 8 | GND | GND |
| 9 | VDD | VDD_3V3 |
| 10 | LEDA+ | VDD_3V3 |
| 11 | LEDK− | 限流电阻 → Q1 集电极 |
| 12 | GND | GND |

连接器固定脚 13/14 接 GND。FPC Pin7/TE 与 T5 GPIO P7 不是同一个概念。

### TE 与 T5 P7（最终方案）

- FPC Pin7/TE 经 **R8=10k（C99198）**接 **T5 P7/J2.17**；TE 是LCD输出，P7必须配置为输入、无上下拉。
- 新屏 Pin9直接接VDD_3V3，旧版 `LCD_PWR=P7` 硬件控制取消；固件必须删除或停用旧P7输出逻辑。
- 需要同步时发送 `TEON(0x35)`；不需要时发送 `TEOFF(0x34)`。小图标局部动画可不等待TE，
  大面积刷新可在TE垂直消隐边沿启动SPI DMA。
- R8可限制旧固件误配置P7输出时的冲突电流，但不能替代正确的GPIO初始化。

### 辅助电路

- SCK/MOSI 串阻位：先装 0Ω，48MHz 出现振铃/异常时换 22Ω。
- Pin9/VDD 就近 **1µF + 100nF**。
- 背光：Pin10/LEDA+ 接 VDD_3V3；Pin11/LEDK− 经限流电阻与 Q1/S8050 低边开关到 GND。
- 规格书背光典型 Vf=3.0V、IF=80mA。当前 10Ω 是保守初值，预计亮度/电流偏低；实测后再决定是否降到
  约 2.2–4.7Ω。若提高到接近 80mA，同时复核 Q1 基极电阻和 GPIO 驱动电流。
- Q1 基极由 P8/LCD_BL 控制，基极串 2.2k，并用 10k 下拉抑制上电闪烁。

### 固件与实机待验证

- ✅ 12P 精确脚序已按 T280C7-C12-26 模块规格书核实，见本节表格。
- 背光是否需要独立限流 / 供电电压（3.3V or 5V）、IM 配置脚（SPI 模式）如何接固定电平。
- 固件：ST7789P3 初始化序列（注意是否需 INVOFF，沿用 v0.2 经验）。

### 验收

- 逐脚连续性与上述表一致；TE经R8连接P7且与GND/VDD无短路；FPC正常方向插入（不反插）。
- 复位、背光、彩条正常，320×240 RGB565。

## F. 44P 排母与电源（简化）

### 变更

- 排母**保持** 2× 1×22 2.54mm（中心距 25.502mm），对插开发板取电与信号。
- 扩展板 5V/3V3/GND **仅来自排母**（无独立供电入口）。
- **5V 走线**：因 WS2812 增至 7 颗，5V/GND 主干建议 **≥0.8mm**（承接 v0.2 电源线宽待核实项）。

### 排母侧 NC 确认（删 USB/复位后）

- T5_RST（J2.2）、UART0_TX/RX（P11/P10）、DP/DN：扩展板内部**不再连接**（原接 CH340C/复位管的走线删除）。

### 验收

- 对插开发板后 3V3/5V/GND 正常；用**开发板 Type-C** 可烧录/通信。
- 扩展板无任何独立电源器件。

## H. 新增/变更器件小结（供 BOM 更新）

**删除**：Type-C、CH340C、LDO、S8050(复位)、电池座、电池开关、2×指示灯及限流、
Type-C/USB ESD、CC 下拉、复位/隔离电阻、CH340C 去耦、VBUS 测试点。

**新增**：
- EC11 编码器 ×1（C9900001788）+ A/B 各 10k 上拉与 10k 串联（C99198，共4）+ 10nF（C100042，共2）+ SW 100nF（C14663，共1）
- 热插拔轴座 Kailh ×7（C2803348）
- **C2890364 / XL-3528RGBW-WS2812B ×7**（替换原 C3646929 三颗并扩到七颗）+ 每颗 100nF（原3颗可复用，新增4颗）+ 47µF 储能电容 ×1
- 12P FPC 连接器 ×1（C2856799）
