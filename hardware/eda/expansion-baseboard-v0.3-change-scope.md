# Expansion Baseboard v0.3 改版范围与待核实事项

> 状态：**设计中**（变更已定义，尚未在 EDA 实施）
>
> 记录日期：2026-09-30
>
> 基线：`Expansion Baseboard v0.2`（旧实物 PCB 丝印 `v1.2.0`，已通过 v1.2 网表核实）
>
> 版本规范：见 `docs/versioning.md`。本板按**决策 A** 使用项目号，PCB 工程/丝印标 **v0.3.0**。
>
> 性质：**重大重构**（非增量改板）。核心方向：**最简化**——扩展板退化为纯
> “按键 + 屏 + 灯”的**无源扩展板**，所有 USB / 电源 / 充电能力交回开发板。

## 0. 变更总览

| # | 变更 | v0.2（基线） | v0.3（目标） |
|---|---|---|---|
| C1 | 扩展板 USB / 串口桥 / 电源开关 | Type-C + CH340C + LDO + 自动复位 + 电池座 + 电池开关 | **全部删除**，烧录/通信/充电/电源全走开发板 |

## 1. C1：删除扩展板 USB / 电源 / 充电电路（最简化）

### 变更内容

删除 v0.2 扩展板上的下列电路，**扩展板不再有任何 USB / 电源管理器件**：

- Type-C 母座（数据 + VBUS）
- CH340C（USB-转-UART 桥）及其外围（去耦、V3 短接、USB 串阻/ESD）
- 供 CH340C 的 LDO（HE9073A33）
- 自动复位/下载电路（S8050 + R_DTR + R_RST）
- 锂电池座（JST PH 2P）
- 电池总开关（SK12D07VG5）
- TX 隔离电阻等仅服务于上述电路的元件

### 由开发板承担

- **烧录 / 通信**：全部经**开发板自带 Type-C**（板载 CH342F ↔ UART0/P10/P11）。
  最终产品外壳需为开发板 Type-C 口开孔（或可拆壳）。
- **供电 / 充电 / 电源管理**：全部由**开发板**负责（开发板 ETA6003 + 其自带 Type-C + 板载电池座 CN1）。
- 扩展板通过 44P 排母从开发板取 3.3V / 5V / GND。

### 影响 / 收益

- 扩展板变为**纯无源功能板**，BOM 大幅精简，成本/风险下降。
- v0.2 咨询文档中“用扩展板 USB 5V 给电池充电”“开发板背面 VCC_BAT/5V 触点取电”等方案**全部作废**（不再需要）。
- “同一时间只插一个 Type-C”“只插一节电池”等 v0.2 安全约束**消失**（扩展板已无对应电路）。

### 验收

- 扩展板 BOM 中不含 Type-C / CH340C / LDO / S8050 / 电池座 / 拨动开关。
- 扩展板与开发板对插后，用**开发板 Type-C** 可正常烧录（`tos.py flash` / TyuTool 自动进 bootloader）与通信。
- 扩展板 3.3V / 5V / GND 均来自 44P 排母，扩展板无独立供电入口。

## 2. C2：6 键 + 热插拔轴座

### 变更内容

- 按键由5个扩展到 **6个：K1–K6**，不再设置K7。
- 安装方式由**直焊**改为**热插拔轴座**（Kailh C2803348，MX兼容）：PCB只放轴座+焊盘，
  键轴可插拔更换。电气上每键一端接GPIO（内部上拉、按下接地、低有效），另一端接GND。

### 布局（决策）

- **K1–K6：每行3个，共两行。**
- **第3行放EC11**，LED7位于EC11下方/附近。
- LED1–LED6分别放在K1–K6正下方。

### 引脚

- 六键使用6个GPIO；原K7规划的P30释放为空闲/预留。见§6。

### 验收

- K1–K6轴座焊盘符合Kailh C2803348封装；插入MX键轴后一脚对应GPIO、一脚接GND。
- 固件按低有效+软件去抖扫描6键；不存在KEY7网络或K7焊盘。

## 3. C3：EC11 编码器替代 5 向摇杆

### 变更内容

- 删除 WS-1002 5 向摇杆，改用 **EC11 旋转编码器**（贴片版，C9900001788；型号 EC11I-152，11mm 增量式，额定 DC 5V）。
- EC11 提供：**A/B 两相正交**（旋转方向 + 步进）+ **按下开关**（旋钮按键）。
- 参考规格书：`datasheets/EC11I-152 Datasheet.pdf`（**已放入并核实**）。

### 引脚与接法（EC11I-152 datasheet 已核实）

| EC11 端子 | 信号 | 接法 | GPIO |
|---|---|---|---|
| A | 编码相 A | 上拉+RC → GPIO(P20) | 1 |
| C | 编码公共端（A/B 中间脚） | 接 **GND** | — |
| B | 编码相 B | 上拉+RC → GPIO(P21) | 1 |
| D | 按键 SW 一端 | GPIO(P22) | 1 |
| E | 按键 SW 另一端 | 接 **GND** | — |

- 编码侧一排 3 脚顺序 **A–C–B**（C 居中公共）；按键侧 2 脚 **D/E**。合计 **3 个 GPIO**。
- **辅助电路按 datasheet 图 1 官方推荐**：A/B 各「10k 上拉 + 10k 串联 + 0.01µF 对地」RC 去抖
  （上拉接 3V3，非 5V）。详见 `hardware/eda/v0.3-circuit-modification-guide.md` C 节。
  具体阻容值待 datasheet 与实测确定。

### 布局

- EC11 放**第 3 行**（旋钮 + 按下）。

### 已核实（依据 datasheet）

- ✅ `EC11I-152 Datasheet.pdf` 已收录于 `datasheets/`，脚序已核对：
  编码侧一排 3 脚顺序 **A–C–B**（C 居中为公共端），按键侧 2 脚 **D/E**；
  规格书 4-3 条明确推荐「以 A 相为参考基准」判方向，15 脉冲/360°（带卡点）。
- 本文所列 A/B/C + 按键 2 脚与 datasheet 成品图一致，可据此画图/写固件。

### 验收

- 顺/逆时针旋转在 A/B 上产生正交脉冲，固件可判方向与步进。
- 旋钮按下 SW 脚对 GND 导通。
- C / 按键公共端确实接 GND。

## 4. C4：7× C2890364 / XL-3528RGBW-WS2812B（每键下方 1 颗）

### 变更内容

- WS2812保持 **7颗**：LED1–LED6分别位于K1–K6下方，**LED7位于EC11下方/附近**作为旋钮状态灯。
- 器件由 v0.2 的 **C3646929 / XL-0807RGBC-2812B（2.0×1.8mm）**改为
  **C2890364 / XL-3528RGBW-WS2812B（3.5×2.8×1.85mm）**。
- JLC 封装：**`LED-SMD_4P-L3.5-W2.8-BR-1`**。
- 新器件脚序：**1=GND、2=DI、3=VDD、4=DO**；旧器件为
  `1=DO、2=GND、3=DI、4=VDD`。禁止沿用旧封装焊盘编号。
- 仍为单线菊花链：P4→U2→R3→LED1.Pin2(DI)，LED1.Pin4(DO)→LED2.Pin2(DI)→…→LED7。
- 数据脚不变：**P4 / J2.20 / SPI1_MOSI**，经 **SN74LV1T34**（3.3V→5V），使用 SPI WS2812 驱动。

### 电气

- VDD=4.5–5.5V，接 VDD_5V；每颗 Pin3–Pin1 就近 **100nF** 去耦。
- 保留首颗入口 R3=100Ω；灯链入口增加 **47µF**（允许 10–47µF）储能电容。
- 800kHz，GRB 高位先发，RESET 低电平 **≥80µs**。
- 单颗全白典型约 36.5mA；7 颗全白典型约 **255.5mA @5V**，供电按 **≥300mA** 留余量。
- 丝印必须标出 Pin1 斜角（顶视图右下）和 `DI→DO` 数据方向。

### 验收

- 逐颗核对 Pin1=GND、Pin2=DI、Pin3=VDD_5V、Pin4=DO。
- 7 颗可独立寻址；菊花链顺序和 GRB 色序正确。
- 第 7 颗不焊时，前 6 颗仍可正常驱动。
- 5V 在 7 颗全白时压降建议 <0.25V。

## 5. C5：12P LCD（ST7789P3）替代 18P

### 变更内容

- LCD 由 **18P（CL28CK230-18A，含 RTP 电阻触摸）** 改为 **12P（T280C7-C12-26，ST7789P3，2.8" IPS，320×240）**。
- FPC 连接器改为 **0.5mm 12P 下接翻盖式**（讯普 FPC-05F-12PH20，C2856799）。
- **取消触摸**：12P 版只保留 SPI + 背光（原 18P 的 15–18 触摸脚不再有）。
- 参考资料：`datasheets/TFT-IPS_2.8_12Pin/单屏-插接12P-T280C7-C12-26/`
  （`ST7789P3_SPEC_V1.0.pdf`、`T280C7-C12-26-V1-产品规格书`、`结构图`、`产品正反图.png`）。

### 引脚（T280C7-C12-26 模块规格书已核实）

| FPC Pin | 信号 | v0.3 接法 |
|---|---|---|
| 1 | GND | GND |
| 2 | RESX | LCD_RST → T5 P6 |
| 3 | SDA | LCD_MOSI → T5 P16（串 0–22Ω） |
| 4 | SCL | LCD_SCK → T5 P14（串 0–22Ω） |
| 5 | CSX | LCD_CS → T5 P15 |
| 6 | DCX | LCD_DC → T5 P17 |
| 7 | **TE** | **NC/悬空**；TE 是 LCD 输出，未使用时规格书要求 open |
| 8 | GND | GND |
| 9 | VDD | VDD_3V3 + 就近 1µF/100nF |
| 10 | LEDA+ | VDD_3V3 |
| 11 | LEDK− | 经限流电阻 + Q1 低边开关到 GND |
| 12 | GND | GND |

连接器 FPC-05F-12PH20 的机械固定脚 13/14 接 GND。

- **T5 P7 不再作为 LCD_PWR**：新屏 Pin9 直接接 VDD_3V3，扩展板没有 LCD 电源开关。
- FPC Pin7/TE 经 **R8=10k（C99198）**接 T5 P7/J2.17；P7 配置为3.3V GPIO输入、无上下拉。
- 固件取消旧 `LCD_PWR=P7` 输出控制；需要同步时发送 `TEON(0x35)`，不需要时发送 `TEOFF(0x34)`。
- R8 同时限制旧固件误把 P7 配为输出时的冲突电流，但正式固件仍必须先把 P7 配成输入。
- 背光 Pin10/11：规格书典型 Vf=3.0V、IF=80mA；当前 10Ω 限流是保守初值，按实测亮度/电流再调整。
- SPI 数据线 SCK/MOSI 已留串阻位，可先 0Ω，出现振铃/显示异常时改 22Ω。

### 验收

- 12P FPC 座为 0.5mm 下接，Pin1 方向与屏 FPC 一致（不再依赖反插）。
- FPC Pin7 经 R8=10k 接 T5 P7/J2.17，与 GND/VDD 无短路；P7 固件配置为输入。
- 复位、背光、彩条显示正常，320×240 RGB565。

## 6. v0.3 引脚分配（建议）

**输入总需求 = 6键 + EC11(A/B/SW) = 9 GPIO**。原K7规划的P30释放为空闲/预留。
（均从44P排针J1/J2引出、未与开发板板载功能冲突。）

| 逻辑 | T5 引脚 | 排针 | 说明 |
|---|---|---|---|
| K1 | P24 | J2.13 | 键（热插拔轴座） |
| K2 | P25 | J2.8 | 键 |
| K3 | P26 | J2.9 | 键 |
| K4 | P27 | J2.12 | 键 |
| K5 | P23 | J2.7 | 键 |
| K6 | P32 | J2.14 | 键（原 NAV_UP 脚复用） |
| P30 | — | J2.11 | 空闲/预留（取消K7后释放） |
| EC11_A | P20 | J2.4 | 编码相 A |
| EC11_B | P21 | J2.5 | 编码相 B |
| EC11_SW | P22 | J2.6 | 旋钮按下 |
| WS2812_DIN | P4 | J2.20 | SPI1_MOSI（经 SN74LV1T34，不变） |
| LCD SCK/MOSI/CS/DC | P14/P16/P15/P17 | J1 | 开发板占用，不变 |
| LCD RST/BL | P6/P8 | J2 | 复位与背光控制 |
| LCD TE | P7 | J2.17 | FPC Pin7经R8=10k接入；输入、无上下拉；取消旧LCD_PWR |

- EC11 公共端 C、按键公共端、各键另一端均接 GND。
- 富余空闲脚（P31/P34/P36/P44–47/P19/P18/P13/P12）留作布线微调 / 后续扩展。
- 以上为**逻辑分配草案**；最终按 PCB 布局（K1–K6 两行 + 第 3 行 EC11、每键下 WS2812）就近优化，
  并跑 `check_pins.py` 校验。

## 7. 保持不变

- LCD 到 T5 的 SPI0 主组与 RST/PWR/BL 引脚（P14/P16/P15/P17/P6/P7/P8）。
- WS2812 数据脚 P4（SPI1_MOSI）+ SN74LV1T34 电平转换 + 官方 SPI 驱动。
- 44P 双 1×22 排母（J1/J2）对插开发板、取 3.3V/5V/GND 的方式。
- 输入低有效 + 内部上拉 + 软件去抖的基本电气策略。
