## 3. 需确认的不一致项（非错误，影响文档一致性）

### 3.1 LED 构成澄清：3 颗 WS2812 + 2 颗普通指示灯（更正 2026-08-24）
> ⚠️ **本报告初版误判更正**：初版曾写"PCB 有 5 颗 WS2812"，经逐器件封装核对，**实际为 3 颗 WS2812 + 2 颗普通红色指示灯**，WS2812 数量与文档记载的 3 颗一致（文档正确）。

- **LED1 / LED2 / LED3** = WS2812B（封装 `LED-SMD_4P...WS2812B`），菊花链，每颗就近 100nF 去耦 ✅。
- **LED4 / LED5** = 普通红色 0603 LED（封装 `LED0603-RD_RED`），是**电源指示灯**（文档此前未记录）：
  - **LED4**：`VBUS → R6 → LED4 → GND` = **Type-C VBUS(5V) 供电指示**。
  - **LED5**：`BAT_P → R10 → LED5 → GND` = **电池(BAT_P) 供电指示**。
- 待办：LED4/LED5 及其限流电阻 R6/R10 需补入 `netlist.md`、`bom.md`、`docs/prd.md §3.1`（已在 2026-08-24 文档一致性更新中处理）。

### 3.2 母排位号：文档 H1/H2 vs PCB 单个 U1
- 机械等价且正确（22×2、2.54mm、25.476mm）。
- 位号命名与 `netlist.md`（H1/H2）不一致，建议在网表注明"PCB 合并为 U1（TUYA_T5_CORE）"。
- ⚠️ 注意：PCB 中另有一个位号 **H1** 是独立的 **2P 插针**（网络 GND / BAT_P），与旧文档中"母排 H1"无关，勿混淆。

## 4. 沿用原理图阶段的非阻塞建议（PCB 层保留提示）

1. **电池开关 SK12D07VG5 额定 0.3A**：整机峰值（T5≈150mA + LCD≈40mA + WS2812×3 全白≈180mA + 2 颗指示灯≈数 mA）可能触及/超 0.3A。缓解：固件限 WS2812 亮度，或换 0.5A/1A 开关。
2. **WS2812 DIN 串阻**：EDA 实际**已有 R3 串在 WS_DIN_5V**（U2.Y→R3→LED1.DIN）。原理图审核报告中"缺串阻"的结论应更正为"已具备"。（R3 阻值以 EDA 原理图为准）
3. **背光限流电阻**：EDA 背光限流路径为 R1（LCD_LEDK 侧），阻值以 EDA 原理图为准、按屏实测亮度定值。（注意：旧文档把背光限流写作 R6，EDA v1.0 中 R6 实为 VBUS 指示灯限流，位号已重编）
4. **丝印 / ESD**：电池座"⚠ 同时只插一节电池"丝印；摇杆/长走线可选 ESD 焊盘。

## 5. 建议进一步人工目视确认（API 难以量化）

- **USB D+/D- 与 LCD SPI 正下方底层 GND 是否连续无裂缝**（铺铜已覆盖两层，裂缝需铺铜/3D 视图目视）。
- **FPC1 在底层（背面下接翻盖座）**：确认与外壳屏开窗方向一致（PRD H4：下接 vs 上接极性）。
