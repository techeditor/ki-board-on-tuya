> 对象：AgenticKeyboard / Expansion Baseboard（对应已审核原理图 P1 V1.0）
> 依据：`hardware/eda/review_report_2026-08-22.md`（已审核，无阻塞错误）、
> `hardware/pinmap/`（引脚/网表/BOM）、`enclosure/`（外壳开窗）、各器件 datasheet。
> 定位：T5AI-Core 开发板经 44P 排针插到本扩展板；本板承载输入/LCD/USB-UART/电池/WS2812。
> 工艺基准：嘉立创**双层板**（1oz/35µm 铜厚）默认工艺。核实日期 2026-08-23。

## 1. 叠层与网络分类

双层板，**底层（Bottom）尽量整片地平面**，顶层走信号+电源。

| 网络类别 | 网络 | 处理原则 |
|---------|------|---------|
| 高速差分 | USB_DP / USB_DN | 短、并排、等长、下方连续地；参考 90Ω 差分 |
| 高频单端 | LCD_SCK / LCD_MOSI (48MHz) | 短、少拐弯、少过孔；预留阻尼电阻位 |
| 大电流 | VDD_5V / GND（WS2812 域）| 加粗，见 §3 |
| 中电流 | VBUS / CH340_3V3 / VDD_3V3 | 中等宽度，见 §3 |
| 低速信号 | KEY×5 / NAV×5 / UART / DTR/RTS/RST / LCD_RST/DC/CS/BL | 常规 10–12mil 即可 |

## 2. 线宽建议（双层 1oz，ΔT≈10°C 温升，含裕量）

> 参考 IPC-2221 外层：1oz 铜、10°C 温升下约 **1A ≈ 0.3mm(12mil)**、**2A ≈ 0.7mm(28mil)**。
> 本板电流都不大，按下表取值即可（均留 2× 以上裕量）。

| 网络 | 估算电流 | 推荐线宽 | 备注 |
|------|---------|---------|------|
| **VDD_5V**（WS2812×3 + U3）| 峰值 ~180–200mA | **≥0.4mm (16mil)**，主干 0.5mm(20mil) | 3 颗全白最大；与音频共用开发板 5V 升压域 |
| **GND** | 汇流 | **整片地平面** + 过孔缝合 | 见 §4 |
| **VBUS** | CH340 ~30–50mA（经 F1）| 0.3mm (12mil) | Type-C→F1→LDO |
| **CH340_3V3**（LDO 输出）| ~30mA | 0.3mm (12mil) | 独立轨 |
| **VDD_3V3**（LCD 等，来自排针）| LCD ~40mA + 逻辑 | 0.3–0.4mm (12–16mil) | |
| **BAT_CELL_P / BAT_P**（电池路径）| 峰值 <0.3A（受开关限）| **≥0.4mm (16mil)** | 经 SW1 开关；见 §7 电流校核 |
| **LCD 背光回路**（LEDA/LEDK/R6/Q2）| 80–100mA | 0.3mm (12mil) | VLED≈3.1V |
| USB_DP / USB_DN | 信号 | **0.25–0.3mm (10–12mil)**，两根等宽等距 | 差分，见 §5 |
| LCD_SCK / MOSI (48MHz) | 信号 | 0.25mm (10mil) | 短直，见 §6 |
| KEY / NAV / UART / 复位 / LCD 控制 | 信号 | 0.25mm (10mil) | 低速，常规 |
| 通用信号最小 | — | ≥0.15mm (6mil) 嘉立创安全 | 尽量别低于 0.2mm |

**过孔**：信号孔 0.3mm 钻/0.5mm 盘；电源/地缝合孔 0.3–0.4mm 钻。载流 >0.5A 的过孔用 2 个并联。

## 3. 电源分区与去耦（对应原理图）

### USB / CH340 / LDO 电源链
```
Type-C VBUS → F1(0.5A PTC) → VBUS → U2(LDO HE9073A33) → CH340_3V3 → U1(CH340C) VCC+V3
```
- **F1 紧靠 Type-C VBUS 脚**；VBUS 铜只在 USB 区，**不铺到系统区**。
- LDO 输入 **C5/C6/C12(10uF+…)**、输出 **C9(10uF)** 就近 U2 的 VIN/VOUT 脚，回地短。
- **C1(100nF)+C2(1uF) 紧贴 U1 的 VCC(pin16)/V3(pin4)**，去耦环路面积最小化。
- CH340_3V3 是独立轨，**不与系统 VDD_3V3/VDD_5V 铜相连**（防倒灌，原理图已隔离，布线勿误接）。

### 5V 域（大电流，重点）
- VDD_5V 来自排针（开发板 LN2220 升压），供 **WS2812×3 + U3(SN74LV1T34) VCC**。
- **主干 0.5mm，分支 0.4mm**；每颗 LED **VDD 脚旁 100nF（C7/C8/C10）贴脚放**，去耦到最近地。
- 3 颗 LED 的 VDD 尽量**星型/短链**供电，别串很长细线（压降致末端偏色）。

### 3V3 域
- VDD_3V3 来自排针，供 LCD(经屏 P7 使能)、U3 的 A 侧参考（实际 U3 只有 A 输入+VCC，VCC=5V）。
- LCD FPC 电源脚 **就近 1uF(C4)+100nF(C3)** 去耦。

## 4. 地（GND）处理

- **底层整片地平面**，顶层器件下方地尽量连续。
- **USB D+/D- 与 LCD SPI 走线正下方的地不要被割裂/掏空**（保证参考回流路径）。
- 大面积铜与地**多打缝合过孔**（尤其 USB 连接器屏蔽壳、Type-C GND、电池 GND、LED 域）。
- Type-C 外壳/Shield 接地：经**小电阻或直接**到 GND（按你习惯；直连最简单）。
- 数字地与"大电流 5V 域回地"尽量分别汇入地平面不同区域后再汇合（单点思路，双层板不必刻意分割，保证平面完整更重要）。

---

## 5. USB 差分（最关键）

- **ESD（D1/D3 JEB05C）放在最靠近 Type-C 的位置**，D+/D- 先过 ESD 再进 CH340 UD+/UD-。
- USB_DP / USB_DN **并排等长走线**，间距均匀，全程**短、直、少过孔**；两根线长度差尽量 <2–3mm。
- 下方保持**连续地**参考；不要跨越地平面裂缝。
- Type-C 的两组 D+/D-（A6/B6、A7/B7）在原理图已于结点合并 → PCB 上就近汇成一对再走向 CH340。
- CC1/CC2 的 **R4/R5(5.1k) 就近 Type-C**。
- USB2.0 全速（12Mbps）容差大，两层板做不到严格 90Ω 也可用，但上述"短/并排/连续地"必须做到。

---

## 6. LCD SPI（48MHz）

- SCK(P14)/MOSI(P16) **短、少拐弯**；CS/DC/RST 常规。
- **预留 R1/R2 = 22Ω 阻尼电阻 0402 焊盘**（串在 SCK/MOSI）：打样先贴 **0Ω**，实测振铃大再换 22Ω。
- FPC 座下方地完整；FPC 走线避免长距离与 WS2812/USB 并行耦合。
- 背光 R6(10Ω)/Q2 就近 FPC 的 LEDK/LEDA 脚。

---

## 7. 电池路径与开关（安全）

- 路径：`BT1(+) → BAT_CELL_P → SW1(SK12D07VG5) → BAT_P（并入开发板同 BAT 网）`。
- **线宽 ≥0.4mm**；SW1 触点电阻 ≤30mΩ。
- ⚠️ **电流校核**：SW1 额定 **DC50V/0.3A**。整机峰值 = T5(~150mA)+LCD(~40mA)+WS2812(全白~180mA) **可能触及/超 0.3A**。
  - 缓解：**固件限 WS2812 亮度**把 LED 峰值压到 <60mA；或改用 0.5A/1A 额定开关。PCB 焊盘可兼容更大开关更好。
- ⚠️ **并联安全丝印**：BAT 与开发板电池座并联同一网络 → 丝印标注 **"⚠ 同时只插一节电池"**。
- 测试点 TP_BAT1/TP_BAT2/TP_GND1 做成**露铜测试盘/探针点**。

---

## 8. 输入（按键/摇杆）

- K1-5、JOY1 均低有效（一端 GPIO、一端 GND），消抖在固件。
- **每个输入脚预留对地 0402 焊盘**（100nF 硬件消抖，可选，不贴不影响）。
- **金属外壳/长走线建议**：至少摇杆、可触及的键脚加 **ESD（LESD5D5.0 或等效）**——PCB 预留焊盘，按需贴。
- 摇杆 WS-1002 脚序 ①A ②Center ③B ④D ⑤Com ⑥C（⑤→GND），布线按 netlist。

## 12. 布线顺序（电源线 vs 信号线）

> 核心原则：**先难后易、先关键后一般、先定死后灵活**。
> 一句话：**敏感高速信号 → 电源 → 普通信号 → 铺地**。

### 第 0 步：布线前准备
- 锁定关键器件位置（H1/H2 母排 25.5mm、Type-C、FPC、按键阵列），**布线前定死**，别边布边挪。
- 设好线宽规则/网络类（见 §2）：电源类 / GND / USB 差分 / SPI / 普通信号分别设默认线宽。
- 底层规划为**地平面**（先留空，最后铺）。

### 第 1 步：关键/敏感信号 **优先**（先占最优通道）
1. **USB 差分 D+/D-（USB_DP/USB_DN）** —— 最先布。短、并排、等长；ESD(D2/D5) 紧贴 Type-C；下方地完整。
2. **LCD SPI 高速线（LCD_SCK/LCD_MOSI，48MHz）** —— 其次。短直、少过孔，经阻尼 R11/R12 到 FPC。
3. 时钟/晶振 —— 本板无（T5 模组内置），跳过。

### 第 2 步：电源线（**信号之后、铺地之前**）
按电流/重要性：
1. **VDD_5V**（WS2812+U3，峰值~180mA）→ 主干 0.5mm。
2. **VBUS / CH340_3V3 / VDD_3V3** → 0.3mm；⚠️ **CH340_3V3 独立轨，勿与系统电相连**。
3. **电池路径 BAT_CELL_P / BAT_P**（经 SW1）→ 0.4mm。
4. **去耦电容跟着电源走**：布芯片 VCC 时顺手接好其去耦电容（C1/C2 贴 CH340、每颗 LED 的 100nF 贴脚）并就近打地过孔。

### 第 3 步：一般信号线（最后布普通线，填空即可）
- KEY1-5、NAV×5、UART TX/RX、LCD 控制线(CS/DC/RST/BL/PWR)、复位 DTR/RTS/T5_RST、WS_DIN_3V3。
- 低速不敏感，10mil 常规线宽，哪里有空走哪里。

### 第 4 步：地（GND）—— 最后处理
1. 先连必须单独走线的地（敏感回流、Type-C shield）。
2. **底层整片铺铜地平面（pour GND）**。
3. **地缝合过孔**：USB 连接器、大电流 5V/电池区、各去耦电容地、跨层信号旁。
4. 检查 USB/SPI 走线**正下方地连续无裂缝**。

### 第 5 步：收尾
- 补漏网络、优化拐角、DRC、3D 比对外壳、铺铜重灌。

### 顺序速查表
| 阶段 | 布什么 | 原因 |
|------|--------|------|
| 1 | 敏感信号 (USB 差分 / SPI) | 最挑路径，先占最优通道 |
| 2 | 电源线 (5V→VBUS/3V3→电池) | 要粗、要规划电流路径，在信号让路后布 |
| 3 | 普通信号 (KEY/NAV/UART/LCD 控制) | 不挑，填空即可 |
| 4 | 地平面 (铺铜 + 缝合过孔) | 最后铺，包住一切、保证回流 |

### 本板额外提醒
- **CH340_3V3 独立轨**：布电源时别手滑连到系统 3V3/5V（原理图已隔离，PCB 别桥接）。
- **USB 差分下方地**：布 D+/D- 时就保证底层地平面在该区域完整，别等铺地才发现被别的线割断。
- **5V 域与地缝合**：WS2812 电流大，5V 干线及其地回路要粗 + 多过孔。
- **去耦电容"跟着电源走"**：布芯片 VCC 时顺手接好去耦并就近打地过孔，别拖到最后。
